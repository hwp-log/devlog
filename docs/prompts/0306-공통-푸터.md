## 1. 한 줄 요약

저작권·데이터 출처(한국문화정보원)·문의 이메일을 담은 공통 푸터를 신설. 헤더와 톤을 통일하되 유리 질감 복사는 과하다고 판단해 배경(연회색)+구분선만 사용했고, SpotFinder(풀스크린 지도)는 푸터에서 제외.

---

## 2. 왜 / 목적 / 이유

- **왜**: 서비스 하단에 저작권·데이터 출처·문의처를 담을 공통 푸터가 없었음. 공공데이터(한국문화정보원) 출처 명시는 데이터 사용상 필요.
- **목적**: 저작권·출처·연락처를 일관되게 노출하는 공통 푸터 확보.
- **이유**: 출처 명시(한국문화정보원 제공)는 공공데이터 활용 서비스의 기본 요건. 문의 채널(hello@dotrip)도 함께.

## 5. 결과 / 배운점

### 결과
- 저작권·출처·문의를 담은 공통 푸터가 Story 등 일반 페이지 하단에 노출.
- SpotFinder(지도)는 제외 — 풀스크린 특성상 하단 푸터가 지도를 밀어내면 안 됨.

### 배운점 (판단 여정)
- **헤더-푸터 색을 억지로 맞출 필요 없음**: 처음엔 헤더 톤과 통일하려고 유리 질감(glass) 복사를 시도했으나 과하다고 판단(푸터는 sticky도 아니라 유리 질감이 불필요). web_search로 "헤더-푸터가 같은 색일 필요 없고, 본문과 같은 배경 + 구분선이 표준"임을 확인. 결국 **연회색 배경(#F7F7F8) + 구분선**으로 정리 — 흰 면적이 넓으면 눈이 피로한데, 연회색 푸터가 그걸 완화하는 부수 효과도.
- **로고 형태 시행착오**: 심볼만 쓰는 축약 로고를 시도했으나 어색해서 풀 로고(D●trip)로 되돌림.
- **경계 결정의 반복**: 색 튐 → 헤더 톤 통일 시도 → 유리 복사는 과함 → 경계선만 → 연회색 배경 → 심볼 로고 시도 → 풀 로고 복귀. 여러 안을 거쳐 "표준(본문 배경+구분선)"으로 수렴.

---

## 결정 (Decisions)

- **푸터 = 본문 배경(연회색) + 구분선** — 헤더 유리 질감 복사는 과함(sticky 아니라 불필요). web_search로 "본문 배경+구분선이 표준" 확인. 연회색은 흰 면적 눈피로 완화 효과.
- **SpotFinder 제외** — 풀스크린 지도라 하단 푸터 부적합. ProtectedMain 경로 분기.
- **풀 로고 유지** — 심볼만 축약은 어색해 D●trip 풀 로고로.
