## 이 커밋에서 나온 문제 2건

**① 번호 부여 규칙이 16분 사이에 갈렸다**

```
57e94fa  docs: 0312-0313 작업 기록 추가        ← 번호 없음
88c3995  docs: 0327 회고 3건 작성 - 작업 기록 추가  ← 번호 있음  (16분 뒤)
```

같은 날 같은 성격의 docs 커밋인데 한쪽만 번호를 소비했다. 이유는 확인되지 않았다.

**② 이 커밋이 만든 3편만 머리말 서식이 다르고 소요시간이 빠졌다**

앞(0312·0313)과 뒤(0328 이후)의 회고는 전부 `작성일 / 소요시간 / 관련 커밋` 한 줄 서식을 갖고 있는데, 0327이 만든 3편은 볼드 리스트형이고 소요시간 항목이 아예 없다. 한 커밋에서 여러 편을 찍으면서 머리말을 새로 만든 것으로 보인다.
