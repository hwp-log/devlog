# 0194 회고: 커버 미보유 스팟 플레이스홀더 개선

작성일: 2026-07-14 / 소요: 약 30분 / 커밋: 82f6e71

## 1. 한 줄 요약
"No Image" 회색 박스를 중성 그라디언트 + 🎬 + 작품명으로 바꿨다 — 작품색·PRIMARY를 쓰지 않는 근거와 함께.

## 2. 왜 / 목적 / 이유
- **왜**: 커버 27곳이 빈칸이라 화면이 성의 없어 보였다.
- **목적**: CSS-only, 3종 크기 차등(히어로 210px 작품명 동반 / 마커 72.5px 아이콘 / 리스트 48px 소형). 마커 선택 카드는 항상 표시로 변경.
- **이유**: 작품별 색 매핑은 코드에 존재하지 않음(실측) — 만들면 27개가 전부 같은 파란 박스. PRIMARY는 wayfinding 신호(마커·pill·길찾기) 전용 — 콘텐츠 썸네일로 확장하면 "여기를 눌러라"의 의미가 희석된다.

## 3. 작성한 프롬프트
사진 API 보류(KorService2 구독 대기) + 플레이스홀더 선행. 새 색 토큰 금지, 기존 토큰만.

## 5. 결과 / 교훈
- 교훈: 빈 상태 디자인은 "없음을 감추는 것"이 아니라 "없음을 정직하게, 그러나 성의 있게" 보여주는 것.
