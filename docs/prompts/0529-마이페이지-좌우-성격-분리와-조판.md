## 1. 한 줄 요약

MyPage를 시안 0529에 맞춰 좌우 성격을 카드 유무로 분리(왼쪽 = 개방 캔버스, 오른쪽 = 설정 카드 3장)하고,
섹션 제목 2px 실선·지표 밴드·hairline 목록 행·버튼 3급·토큰 색으로 재조판 + DangerZone을 "계정 삭제"로 한글화.

---

## 2. 왜 / 목적 / 이유

- **왜**: (초안: MyPage만 구 스타일(glass·slate 하드코딩·다크 미대응)로 남아
  0512~0528에서 세운 공통 기준과 어긋났음)
- **목적**: (초안: "읽기 표면은 개방 캔버스, 카드는 조작 표면에만"(0371)을
  설정 화면에도 적용 — 카드 유무 자체가 좌우 성격(보는 정보 vs 바꾸는 설정)의 표시가 되게)
- **이유**: (초안: 두 열을 같은 카드로 감싸면 성격이 갈리지 않음.
  모바일 1열에서도 "카드 시작점 = 설정 시작점"이라 순서만으로 성격이 유지됨)

## 5. 결과 / 배운점

### 결과
- 좌우 성격이 카드 유무로 표시됨. 모바일 1열에서도 카드 시작점 = 설정 시작점.
- 커밋 3개(구조 1 + 조판 2), 각 커밋 후 `npx tsc --noEmit` 통과. mypage 기존 테스트 없음.
- 입력 필드 text-sm(14px) → text-base(16px)로 iOS 자동 확대 위반 해소 (§5).

### 시안 실측이 참고치와 달랐던 지점 (시안 우선 적용)
- 지표 값 굵기 **400** (참고치 700) — 시안 해설 "20px vs 12px 크기 대비로 충분"
- 다크 입력 테두리 #3a3e41 (참고치 #2a2d2f는 카드 테두리)
- 최근 활동 이름 450 → 정적 Pretendard(100단위)라 **500(font-medium)** 채택

### 토큰 색차 (기존 토큰 재사용, 시안값 억지 매칭 안 함 — 사용자 확정)
- fg #191a1c/#f0eee8 (시안 #17191a/#f2f4f5), hairline 라이트 #f1f2f3 (시안 #ebedee)
- fg2/muted 다크가 웜톤 #c8c4be/#7a7870 (시안 쿨그레이 #c9cdd0/#8b9196) —
  **다크 실화면에서 어색하면 회색 축 전체 이동을 별건으로** (사용자 지정 확인 항목)
- danger #ef4444/#f87171 (시안 #d0453f/#ef8592), danger-surface #fef2f2/#3a2626 (시안 #fdf3f2/#2a1a19)
- 카드 bg-card #f2f2f5 (시안 #fff — 흰 셸 위 구분에는 기존값이 적합)
- 신규 토큰 0개. 주요 버튼 호버(#3b8ff3/#6bafff)는 기존 CTA 관례(무호버) 따름

### 시안·기능 사이 조정 (기능 무가감 우선)
- 카드 저장 버튼: 시안은 1개, 실제는 닉네임 저장(카드 하단 주요) + **사진 저장**(파일 선택 시에만
  노출, 보조 조판)으로 분리 유지 — 액션 병합 안 함
- 아바타 **제거** 버튼: 시안에 없지만 기능 유지 (소형 텍스트)
- DangerZone 펼침(확인 문구 입력) 플로우: 시안에 없지만 유지, 재조판만
- 주요 버튼 글자: 시안 #fff ↔ 0524의 primary-fg(대비 6.39:1) 이력 충돌 → 사용자 지시로 **흰색**
  (파랑 위 흰 글자 대비 2.74:1 — 0524 이력 참고)

## 결정 (Decisions)

- MyPage 회색은 fg/fg2/muted 기존 축 재사용 — 시안 쿨그레이와의 색차는 허용, 어색하면 축 전체 이동을 별건으로 (0529)
- 아바타 미리보기 상태는 mypage 지역 Context로만 공유 — 전역 승격 금지, 공유값 최소 (0529)
- 카드 안에서는 섹션 2px 실선을 쓰지 않는다 — 카드 분리 자체가 경계 (0529, 시안 해설)
