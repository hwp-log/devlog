## 2. 왜 / 목적 / 이유

### 왜 이 파일 작성?
- **왜**: 기존 DECISIONS.md 폐기 결정 (2026-05-16). 결정 = 각 회고에 분산 작성하는 방식으로 전환.
- **목적**: 0014 이전 시점 결정 = 매칭 회고 없음. 옛 결정 보존을 위한 별도 회고 작성.
- **이유**: 결정 = 검색 가능해야 함. 매칭 회고 없는 항목 = 1개 회고에 묶음 작성하는 게 단순. 시간 순 X / 카테고리 단위로 정리.

### 왜 결정 = 회고에 분산?
- **왜**: DECISIONS.md = 전체 보기 부담. AI 토큰 낭비. 결정 ↔ 작업 분리 발생.
- **목적**: 작업 시 = 해당 회고만 확인. 결정 = 회고 안에서 자연 검색.
- **이유**: ADR (Architecture Decision Record) 표준 매칭. 1개 결정 = 1개 파일 본질. AGENTS.md = "결정 = docs/prompts/ 검색" 1줄 안내만 작성.

---

## 3. 결과 / 배운점

### 결과
- 옛 결정 14개 보존 완료
- DECISIONS.md 삭제 가능
- 결정 검색 = `docs/prompts/` 전체 폴더 대상

### 배운점
- **결정 ↔ 회고 통합**: 결정 = 작업 시점에 작성. 회고 안에 포함하는 게 자연스러움. 별도 파일 분리 = 컨텍스트 분리 발생.
- **인덱스 = 자동 가능**: AI / 사람 = 파일명 기반 검색 가능. 별도 인덱스 불필요.
