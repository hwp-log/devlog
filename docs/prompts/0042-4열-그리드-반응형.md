# 0042: 4열 그리드 + 반응형 + 레이아웃 폭 확장

## 한 줄 요약

`layout.tsx`의 `max-w-5xl`을 `max-w-7xl`로 갈음 + `/story` 그리드를 `lg:grid-cols-3`에서 `xl:grid-cols-4`까지 확장해서 큰 화면에서도 카드가 충분히 채워지도록 조정.

## 왜·목적·이유

0041에서 velog 스타일 카드를 만들었더니 작은 노트북(13인치)에서는 괜찮은데 외장 모니터(27인치)에서 너무 휑함. 3열에서 카드가 한 줄에 3개만 들어가고 양옆에 빈 공간이 큼.

핵심 결정:

1. **`max-w-5xl` → `max-w-7xl`**: 헤더와 main 모두 갈음. 5xl(1024px)은 블로그용, 7xl(1280px)이 포트폴리오 그리드용으로 더 적합.
2. **그리드 단계 `1 → 2 → 3 → 4`**: Tailwind 표준 브레이크포인트 그대로. md(768), lg(1024), xl(1280).
3. **카드 메타 영역 2줄로 분리**: 태그 한 줄 / 작성자·날짜 한 줄. 카드가 작아져도 가독성 유지.

이건 디자인 미세 조정이라 작업량은 작지만, "포트폴리오답게 보이는" 첫인상에 크게 영향 줌.

## 결과·배운점

**잘 된 점**

- 27인치 모니터: 4열이 화면을 적절히 채움. "포트폴리오" 느낌 확보.
- 13인치 노트북: 3열 유지로 카드가 너무 작아지지 않음.
- 모바일: 1열 그대로, 가독성 유지.

**알게 된 것 — Tailwind 브레이크포인트 + max-w 조합의 의미**

`max-w-7xl`(1280px)을 컨테이너 폭으로 두고 `xl:grid-cols-4`(1280px 이상에서 4열)를 적용한 게 우연이 아님:

- xl 브레이크포인트 = 1280px = max-w-7xl의 정확한 값
- 즉 "컨테이너가 최대 폭에 도달하는 순간 = 4열로 갈음하는 순간"
- 결과: 카드 한 개가 항상 (1280 - gap*3) / 4 ≈ 290px 부근 유지 → 4열에서도 카드가 작지 않음

만약 `max-w-6xl`(1152px)을 썼다면 4열 카드가 약 270px로 좁아져서 디자인이 무너짐. **그리드 컬럼 수와 컨테이너 폭은 함께 결정해야 한다**는 교훈.

**메타 영역 한 줄 vs 두 줄**

처음에는 한 줄에 다 넣었는데 4열 카드에서 태그가 길면 작성자·날짜가 잘림. 두 줄로 분리하니:
- 태그 줄: flex-wrap으로 여러 줄까지 허용
- 메타 줄: 항상 한 줄, 작성자·날짜만

→ "정보 밀도"보다 "정보 분리"가 작은 카드에서 더 중요. velog/Notion도 메타 영역은 항상 분리.

**언제 layout을 갈음할지의 판단**

처음에는 "그리드만 4열로 갈음하면 되지 layout까지 갈음할 필요가 있나" 싶었음. 그런데 5xl을 유지하면:
- 4열 카드가 (1024 - gap*3) / 4 ≈ 240px로 좁아짐
- 240px 카드 안에 16:9 썸네일 = 240*9/16 = 135px → 너무 작아서 분위기 안 살림

→ **그리드 확장 결정은 컨테이너 폭 결정과 한 쌍**. 따로 갈음하면 안 됨.
