## 1. 한 줄 요약

CostPlan 목록을 카드 그리드에서 가로 행(row) 랭킹 비교 리스트로 바꿨다. 인기순(좋아요 수)을 기본 정렬로 두고 순위 뱃지를 붙였으며, 상단에 "N개 코스 · 평균 약 N만원" 요약을 더했다. 평균은 정밀 총액이 아니라 가공된 가격 구간(band)의 중앙값으로 계산해, 0097의 정밀 미전송 경계를 그대로 유지했다.

---

## 2. 왜 / 목적 / 이유

### 평균을 정밀 총액이 아니라 band 중앙값으로

- 왜: 평균을 정밀 총액으로 내면 정밀 금액이 클라에 도착해 있어야 한다. 그 순간 0097에서 "서버 미전송"으로 막은 정밀 금액이 다시 payload에 실리고, 화면엔 "평균 약 21만원"만 떠도 네트워크엔 각 플랜의 정밀 총액이 실려 역산으로 개별 금액이 복원될 수 있다.
- 목적: 상단에 평균이 뜨되, 정밀 총액은 여전히 클라에 도착하지 않는 상태.
- 이유: 클라에 이미 와 있는 가공 구간(band)의 중앙값으로 평균을 냈다 — 이미 가공된 값으로 또 가공하는 거라 정밀 총액을 새로 끌어올 필요가 없다. 0097이 만든 "정밀은 서버에만, 클라엔 구간만" 경계를 그대로 유지한 채 평균이 나온다.

### band 없는 플랜은 평균에서 제외(withBand)

- 왜: 구간이 없는 플랜(비-KRW 등)은 평균 낼 재료(중앙값)가 없다. 억지로 채우려면 정밀값을 끌어와야 하는데, 그건 위 경계를 깨는 일이다.
- 목적: 재료가 있는 플랜만으로 평균을 내고, 없는 플랜 때문에 경계를 뚫지 않는 상태.
- 이유: band가 있는 플랜만 골라(`withBand`) 그들의 구간 중앙값으로 평균을 계산했다. 재료가 없으면 빼고, 정밀을 끌어오지 않는다.

### 카드 그리드 → 가로 행 랭킹 리스트

- 왜: CostPlan은 "남의 계획을 구경·비교하는 곳"인데, 카드 그리드는 한 화면에 적게 보이고 비교가 어렵다. 마이플랜(내 계획 관리)과 성격이 덜 구분됐다.
- 목적: 여러 플랜을 위아래로 훑으며 가격·인기를 비교할 수 있고, 마이플랜과 확실히 다른 "랭킹·비교" 화면.
- 이유: 가로 행 리스트로 바꿔 한 줄에 [썸네일+순위] [제목·지역·작성자·미니 막대] [가격 구간·하트] [chevron]을 배치했다. 인기순 기본 정렬과 순위 뱃지가 "랭킹" 성격을 강화한다. mock/costplan_mockup.html의 구조·수치를 기준으로 따랐다.

> 순위 뱃지는 정렬·필터 적용 후 sorted 인덱스+1이라, 인기순/최신순/가격순을 바꾸면 번호가 다시 매겨진다. 사진은 플랜에 아직 없어 회색 박스 + 사진 아이콘 플레이스홀더로 두고 실제 사진은 후속 작업으로 미뤘다.

```tsx
// 정렬: 'popular'(기본, likeCount desc) + 기존 최신순·가격순
const [sort, setSort] = useState('popular');

// 순위 = 정렬·필터 적용 후 인덱스+1

// 상단 요약 평균 — band 중앙값만, band 없는 건 제외
```

## 5. 결과 / 배운점

- 검증 통과: 행 리스트·순위 뱃지·썸네일 플레이스홀더·by 닉네임·미니 막대·구간·하트·chevron 렌더, 인기순 기본 + 정렬·필터 전환 시 순위 다시 매겨짐, 상단 "N개 코스 · 평균 약 N만원" 그럴듯, payload에 email·정밀 총액 없음(쿼리 미변경), tsc 통과.
- 배운점 1: 파생 통계(평균)도 어떤 재료로 내느냐가 보안을 가른다. 평균은 단일 숫자라 안전해 보이지만, 정밀 총액으로 내면 그 정밀값이 클라에 도착해야 해서 역산이 가능해진다. 이미 가공된 구간(band) 중앙값으로 내면 정밀을 끌어올 필요가 없어, 0097의 경계가 유지된다.
- 배운점 2: 재료가 없으면 억지로 끌어오지 말고 제외한다. band 없는 플랜을 평균에 넣으려고 정밀값을 끌어왔다면 경계가 깨졌을 것이다. `withBand`로 빼는 선택이 경계를 지켰다.
- 배운점 3: 표시 계층 리디자인은 쿼리를 건드리지 않을 수 있다. 데이터(가공 summary·닉네임·하트)는 그대로 두고 레이아웃만 바꿔, 보안 경계와 무관하게 UI 성격(랭킹·비교)만 강화했다.
