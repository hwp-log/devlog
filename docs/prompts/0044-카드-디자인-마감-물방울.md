# 0044: /story 카드 디자인 마감 (물방울 글래스)

## 한 줄 요약

`.glass-outer-interactive` modifier 패턴으로 카드 디자인 분리 + 흰색 0.9 + 4겹 box-shadow + border-radius 36px + hover scale(1.03) + translateY(-8px)로 "물방울" 느낌의 글래스 카드 완성.

## 왜·목적·이유

0043 시드 12개로 카드 그리드가 가득 찼지만 디자인이 평평함. 0037에서 만든 `.glass-outer` (피그마 인스파이어드 글래스 효과)를 재활용하되, `/story` 카드는 hover 상호작용이 다르니 별도 modifier로 분리.

핵심 결정:

1. **modifier 패턴 = `.glass-outer-interactive`**: 기존 `.glass-outer`는 그대로 두고, `/story` 카드용만 별도 클래스. 다른 페이지(예: 로그인 폼) 영향 차단.
2. **디자인 방향 = "물방울"**: 그라데이션·blur 다 시도해보고 최종적으로 흰색 0.9 + 4겹 그림자가 가장 깨끗했음.
3. **border-radius 36px**: 32px도 시도했는데 36px이 "포트폴리오"답고 모던. velog/Notion보다 살짝 더 둥글게.
4. **hover = scale(1.03) + translateY(-8px)**: 살짝 떠오르면서 약간 커짐. 0037에서 만든 `--tw-shadow` 함정 회피하려고 raw CSS transition 사용.
5. **시각 작업 중 커밋 안 함**: 디자인 시행착오 중간 커밋은 의미 없음 → 마지막에 통합 커밋.

## 결과·배운점

**잘 된 점**

- 4열 × 3행 = 12개 카드가 통일된 글래스 디자인으로 가득 차서 "여행 포트폴리오" 분위기 한 번에 완성.
- hover 시 카드가 살짝 떠오르는 효과 — 인터랙티브 느낌.
- `.glass-outer` 원본을 보존하고 `.glass-outer-interactive` 별도 modifier로 분리 → 다른 페이지(로그인 폼 등) 디자인 영향 0.

**알게 된 것 — modifier 패턴의 가치**

처음에는 `.glass-outer` 자체에 hover를 추가할까 했음. 그런데:
- `.glass-outer`는 로그인 폼, 회원가입 폼 등에서도 쓰임
- 폼에서 hover로 카드가 떠오르면 이상함 (인터랙티브 아니니까)
- modifier로 분리하면 의도 명확

```
.glass-outer = 기본 시각 효과만
.glass-outer-interactive = 기본 + hover 인터랙션
```

→ BEM 같은 패턴(Block__Element--Modifier). 한 클래스에 모든 기능을 넣지 말고 책임 분리.

**Tailwind v4 함정 회피 — raw CSS가 답**

0037에서 발견한 `--tw-shadow` transition 함정 때문에 hover 시 그림자가 갑자기 바뀜(스무스 X). 이번에는 처음부터 raw CSS `transition: transform 0.3s ease, box-shadow 0.3s ease`로 처리.

Tailwind v4의 CSS 변수 기반 그림자 시스템은 강력하지만 transition과 안 맞음. 시각 효과가 중요한 컴포넌트는 raw CSS가 안전.

**"물방울" 디자인의 의미 — 4겹 그림자**

box-shadow 4겹의 이유:
1. `0 1px 2px` — 가장 가까운 그림자 (카드 윤곽선 강조)
2. `0 4px 12px` — 중간 (카드와 배경 분리)
3. `0 12px 32px` — 멀리 (떠 있는 느낌)
4. `0 24px 64px` — 가장 멀리 (전체적 깊이감)

한 겹만으로는 평면적, 4겹이 쌓이면 "공중에 떠 있는 물방울" 느낌. Apple의 디자인 시스템(macOS 위젯)에서 자주 보이는 패턴.
