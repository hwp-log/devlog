## 1. 한 줄 요약

MyPlan 목록을 88px 텍스트 행에서 플랜파인더와 같은 판형(240/280px 사진 카드 그리드)으로 옮기고,
소유자 화면에서만 다른 네 가지(공개 상태 칩 · 좋아요의 의미 · ⋯ 편집/삭제 메뉴 · 커버 폴백)를 얹었다.

- **왜**: 내 화면 셋(MyStory · 플랜파인더 · MyPlan) 중 MyPlan만 텍스트 행이라
  화면마다 훑는 법을 새로 배워야 했다.
- **목적**: (초안: 세 목록의 카드 언어를 하나로 맞춰 학습 비용을 없앤다)
- **이유**: (초안: 플랜파인더 카드를 기준으로 삼되, 소유자 화면은
  "보는 화면"이 아니라 "관리하는 화면"이라 상태·조작이 카드 안에 있어야 한다)

## 4. 코드 작성 & 수정

### 1. 카드 상수 공용화 (구조)

플랜파인더 PlanCard 안에 리터럴로 있던 스크림·폴백·그늘·sizes를 `lib/card-tokens.ts`로 옮겨
두 카드가 같은 값을 본다. 한쪽만 바뀌면 두 목록의 사진 위 언어가 갈라진다.

```ts
export const PLAN_CARD_SIZES = '(max-width: 767px) 100vw, 400px';
export const CARD_COVER_OVERLAY =
  'linear-gradient(to top, rgba(10,10,16,0.65) 0%, rgba(10,10,16,0.65) 32%, rgba(10,10,16,0) 44%)';
export const CARD_TEXT_SHADOW = '0 1px 3px rgba(0,0,0,0.7)';
export const CARD_FALLBACK_BG = '#343943';
export const CARD_FALLBACK_FG = '#7a7870';
```

### 2. 상태 칩 — 색은 "공개"에만 (행동)

채움(공개) > 기본 재질(비공개) > 점선(초안)의 **무게 3단**이라 색은 하나만 쓴다.
상태 3종에 색 3개를 주면 상태 언어가 서로 경쟁한다(§9).

```tsx
const PUBLIC_CHIP = 'bg-primary text-white font-semibold';
const DRAFT_CHIP = 'border border-dashed border-white/60 text-white bg-[rgba(10,10,16,0.34)]';
// 비공개는 CARD_PILL_CLASS(플랜파인더 칩과 같은 재질) + 자물쇠
```

### 3. 중첩 링크 회피 — 카드 전체 링크 + 형제 조작 (구조)

카드가 `<a>`면 그 안의 ⋯ 버튼이 중첩 인터랙티브가 되어 무효다.
링크를 `absolute inset-0`으로 깔고 조작 요소를 형제로 올렸다.

```tsx
<div className="group relative h-[240px] sm:h-[280px] rounded-[14px] overflow-hidden">
  <Link href={`/my-plan/${id}`} className="absolute inset-0 flex flex-col">…</Link>
  {!coverUrl && <Link href={`/my-plan/${id}/edit`} className="… z-10">커버 추가</Link>}
  <MyPlanCardMenu planId={id} title={title} isPublic={isPublic} />
</div>
```

### 4. 메타 줄에서 지역 중복 제거 (행동)

플랜파인더는 지역을 칩과 메타에 두 번 쓴다. 칩 자리를 상태에 내준 김에 갈랐다 —
칩 = 지역, 메타 = 작품 · 기간 · 장소 수. 필드는 하나도 안 잃는다.

```tsx
const meta = [movie ?? region, formatCardPeriod(startDate, endDate), `장소 ${spotCount}곳`]
  .filter(Boolean).join(' · ');   // "도깨비 · 10.12~10.14 · 장소 8곳"
```

### 5. 금액 — band 중앙값이 아니라 실제 총액 (행동)

내 플랜이라 금액을 흐릴 이유가 없다. 원화가 아니면 band 자체가 없으므로 정확값+통화기호.

```tsx
const priceLabel =
  total === 0 ? '금액 없음'
  : currency === 'KRW' ? `총 약 ${Math.round(total / 10_000).toLocaleString()}만원`
  : `총 ${formatAmount(total, currency)}`;
```

### 6. Tailwind 충돌을 특이도로 확정 (수정)

`sm:opacity-0`과 `sm:opacity-100`은 특이도가 같아 어느 쪽이 이길지 출력 순서에 달린다(0462와 같은 함정).
열림 상태를 속성 선택자로 올려 순서 의존을 없앴다.

```tsx
data-open={open}
className="… opacity-100 sm:opacity-0 sm:group-hover:opacity-100 data-[open=true]:opacity-100"
```

위험 항목도 같은 이유로 클래스 문자열을 통째로 갈랐다(`hover:text-fg`와 `hover:text-danger`를 겹치지 않게).

## 5. 결과 / 배운점

### 결과
- 커밋 4개(구조 1 · 기능 1 · 조판 1 · 수정 1), 각 커밋 후 `npx tsc --noEmit` 통과.
- `npm run build` 통과. `npm test` = 6 failed / 14 passed (기존 실패 목록과 동일,
  auth 5스위트 + SpotPopup — 회귀 없음).
- 부수 효과로 다크 버그 하나 해소: MyPlan 제목이 `text-[#1A1A1A]` 하드코딩이라
  다크에서 배경에 묻히던 것을 `text-fg`로.

### 시안과 다르게 간 지점 (사용자 확정 필요)
- **다크 회색 3단**: 시안은 쿨(#f2f4f5 → #b9bfc4 → #8b9196), 구현은 기존 토큰(웜 #f0eee8 → #c8c4be → #7a7870).
  회색 축 전체 이동은 모든 화면에 걸리는 별건이라 이번 작업에서 하지 않았다(0529에서 남긴 그 항목).
- **칩 글자 11px** — 기준의 "라벨 12px"보다 1px 작다. 플랜파인더·MyStory 칩과 카드 언어를 맞춘 쪽.
- **필터 드롭다운**: 시안은 "가격대 전체"처럼 라벨을 앞에 붙였으나, 공용 `FilterDropdown`은 값만 보인다.
  플랜파인더와 공유하는 컴포넌트라 건드리지 않았다.

### primary 면 위 글자색 (사용자 지시)
시안은 `#0b1a2b`(primary-fg, 파랑 위 6.39:1)였으나 승인 후 흰색으로 변경 —
0529의 "저장·비밀번호 변경은 흰색으로"와 같은 선택. 흰색은 2.74:1로 AA 미달이며 **알고 수용**한다.
토큰은 그대로 두고 호출부에서만 `text-white`. 레포에 남아 있던 `text-primary-fg` 3곳도 함께 통일했다 —
계획 작성 화면 저장 버튼 2곳(0527)과 플랜파인더 상세 "내 여행으로 담기"(0524).
`grep text-primary-fg` 결과 0건이 됐고, 0524 주석은 "왜 primary-fg였는지 + 왜 지금 흰색인지"로 정정했다.
(토큰 `primaryFg` 자체는 남아 있다 — 정의만 있고 쓰는 곳이 없는 상태.)

### 새로 추가된 것 (기존 화면엔 없던 것)
- 지표에 **"지역 N곳"** — region distinct 개수 파생(새 데이터 아님).
- 평균 금액 `Math.floor` → `Math.round` (기준의 "반올림").
- 계획 1~2개일 때 그리드 마지막 칸의 점선 "새 계획" 타일.

### 배운점
- (초안: 같은 카드를 다른 화면에 옮길 때 진짜 설계는 "무엇을 유지하는가"가 아니라
  "무엇이 이 화면에서만 의미가 다른가"였다 — 좋아요는 남기되 역할이 바뀌었고(누르는 것 → 받은 것),
  그래서 자리도 바뀌었다.)

## 결정 (Decisions)

- **카드 그리드 전환의 유일한 반대 조건은 커버 없는 플랜 비율**이다. 폴백이 절반을 넘으면
  회색 판만 남아 밀도만 잃는다. 실데이터 비율 확인은 미완 — 전환 후 실화면에서 판단할 것.
- **카테고리 비율 막대는 카드에서 뺐다.** 목록에서 비교되는 값이 아니라 한 플랜 안에서 읽히는 값이라
  상세가 원래 자리. (카드 전환으로 잃은 유일한 정보)
- **소유자 그리드의 조작은 ⋯ 오버플로 메뉴**(Drive·Photos·Notion·YouTube Studio 표준).
  삭제는 구분선 아래 danger + confirm — 파괴 행동이 오터치 한 번 거리에 놓이지 않게.
- **상태 표시에 색은 하나만.** 채움/기본/점선의 무게로 3상태를 가른다.
- **통화 혼재 평균은 그대로 남아 있다** — 지표의 평균이 ₩·$·¥ 총액을 섞어 나눈다.
  이번 작업 범위 밖이라 손대지 않았다(별건).
