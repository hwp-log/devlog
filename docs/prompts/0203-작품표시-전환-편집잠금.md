## 2. 왜 / 목적 / 이유
- **왜**: 재사용 seed 스팟은 레거시 movieId가 null — 상세 여행동선에서 작품이 안 떴다(SpotFinder는 조인이라 2편 정상). 0202에서 "상세가 마지막"이라 했으나 story.spots를 찾았지 spot.movie를 안 찾았다 — 전수 조사도 검색어에 갇힌다.
- **목적**: 작품 표시를 spotMovies 조인(대표 1개 + N, 최신 연결순)으로 — 배지 문법을 화면 전체에서 통일. 재사용 스팟의 작품 필드는 disabled + 안내.
- **이유(잠금)**: 공유 스팟의 작품은 공유 자산 — 한 사용자의 편집이 전원에 영향. 시딩 스팟은 공공데이터 출처라 개인이 바꾸면 안 된다. 위키형 편집 권한은 별도 설계(표지: 이름·좌표·설명도 같은 문제).

## 3. 작성한 프롬프트
표시 정책 확정(SpotFinder 동일 규칙) + 편집 변경의 파급 판단 요구 → "2번. 편집 금지(읽기 전용)" 회신.
