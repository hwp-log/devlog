## 1. 한 줄 요약

플랜파인더 상세를 커버 히어로 + 요약 앵커 구조로 개편하고, 그때까지 공개 뷰에서
차단하던 금액 3곳(항목 amount·항공 총액·일정 금액)을 "약 N만원" 근사 표기로 열었다.

---

## 2. 왜 / 목적 / 이유

- 0089 "정밀 지출액 = 개인 경제 정보" 원칙을 이 사이클이 완화했다는 사실만 코드에 남아 있고,
  **완화 근거는 어느 문서에도 없다** (0557 사이클에서 이 공백이 지적되어 원칙 재정의로 이어짐).
  여기에 당시의 판단 근거를 적을 것.

---

## 3. 작성한 프롬프트

기록 없음.

커밋 본문에 남은 목표만 사실로 확인된다:
```
- 상단 히어로 신설(coverUrl, 좌상단 지역 칩, 없으면 생략)
- 요약 앵커 한 줄 추가, 섹션 순서를 일정 → 항공 → 비용으로
- 공개 뷰 금액 차단 3곳 되돌림(항목 amount·항공 총액·일정 표시)
- 항공 카드 2장을 금액 열 없는 2행 표로(총액은 제목 옆 1회)
- 비용 트리맵을 총액·누적 막대·항목별 금액으로 교체
- 일정 금액을 카드 하단으로 이동, 약 N만원 반올림 적용
- 미입력 비용이 "무료"로 표시되던 문제 수정(141건 오표시)
```

## 4. 코드 작성 & 수정

### ① 금액 표기 단일 소스 신설 — `lib/plan/format-approx-cost.ts` (신규)

```ts
/**
 * 0492: 공개 상세의 금액 표기 — KRW는 "약 N만원" 반올림, 그 외 통화는 정확 금액.
 * 목록 카드(0441 priceLabel)와 같은 만원 반올림 규칙을 상세에도 통일한다.
 */
export function formatApproxCost(amount: number, currency: 'KRW' | 'USD' | 'JPY'): string {
  if (currency === 'KRW') {
    return `약 ${Math.round(amount / 10_000).toLocaleString()}만원`;
  }
  return formatAmount(amount, currency);
}
```

## 5. 결과 / 실측

- 미입력 비용이 "무료"로 표시되던 오표시 **141건** 해소 (커밋 본문 수치).
- 히어로 `sizes` 기준: 모바일 100vw / 데스크톱 640px (당시 본문 컬럼 폭).
- 항공 총액 표기 위치는 이 사이클에선 섹션 제목 옆 1회 → **트랙 2(0494)에서 다시 제거**
  ("금액은 비용 섹션이 전담").

### 이후 사이클의 뒤집힘 (사실 기록)

- `formatApproxCost`("약 N만원")는 **0558에서 폐기**되고 전 화면 실값(`formatAmount`)으로 통일.
  파일 자체가 `9005f9b`에서 삭제됨.
- 0492가 완화했던 금액 공개 원칙은 **0557에서 "글 자체를 가림"(visiblePlanWhere)으로 재정의**.
- 히어로 `sizes` 640px은 0534~0535 폭 규칙 편입 시 재계산 대상이 됨.
