# 0301 회고: Story 헤더 타이포 정제

**작성일**: 2026-07-21
**관련 커밋**: `c1fd3ad` style: 0301 Story 헤더 타이포 정제

---

## 1. 한 줄 요약

StoryHeader의 눈썹(eyebrow)과 제목 타이포만 조정 — 눈썹을 라벨화(대문자·자간 확장·굵기 절제)하고, 제목 크기를 20px로 고정하며 굵기를 낮춰 절제된 위계로 정리.

---

## 2. 왜 / 목적 / 이유

> 이 커밋의 판단 근거는 코드에 드러나지 않음. 아래는 변경 내용으로부터의 추정이며, 실제 의도는 기록되지 않았다.

- **왜 (추정)**: 기존 눈썹·제목이 굵고(font-bold/semibold) 반응형 크기(md:text-3xl)라 위계가 과했음. 다른 화면 헤더와의 톤 통일 또는 절제된 미니멀 방향으로의 정리가 필요했던 것으로 보임.
- **목적 (추정)**: 눈썹을 "라벨" 언어(대문자·자간 wider)로 명확히 하고, 제목을 고정 크기·절제된 굵기로 통일.
- **이유**: 기록 없음
---

## 3. 작성한 프롬프트

> 프롬프트 원문은 남아 있지 않다. 타이포 2줄 조정이라 구두 지시였을 가능성.

---

## 4. 코드 작성 & 수정

변경 파일 1개: `app/story/_components/StoryHeader.tsx` (2+ / 2-)

### 변경 내용 (- 전 / + 후)

```tsx
// 눈썹(eyebrow): 라벨화
- text-xs font-semibold ... mb-1
+ text-[12px] font-medium uppercase tracking-wider ... mb-0
//   → 대문자화 + 자간 확장(tracking-wider) + 굵기 semibold→medium + 아래여백 제거

// 제목: 크기 고정 + 굵기 절제
- text-xl md:text-3xl font-bold
+ text-[20px] font-semibold
//   → 반응형(md:text-3xl) 제거하고 20px 고정, font-bold→semibold
```

---

- 제목이 20px 고정·semibold로 절제된 위계.
