## 1. 한 줄 요약

0610 골격 정합으로 사라진 auth 화면 제목을 복원 — 두 화면 공통 태그라인("여행의 시작점을 찍다.")을 화면별 h1("로그인"/"회원가입")으로 교체, signup page.test 통과 전환 + globals.css 경고 축 주석 현행화(0610 warning 부활 반영).

---

## 2. 왜 / 목적 / 이유

- **왜**: 0610에서 /signup을 /login 골격으로 정합하며 카드 상단이 "Dotrip"+태그라인뿐 — 로그인인지 가입인지 구분 불가. signup page.test의 heading '회원가입' 기대도 실패 중이었다.
- **목적**: 두 화면을 형제로 유지하되 어느 화면인지 구분되게. 태그라인은 두 화면 공통 문구라 구분에 기여하지 않아 제거.
- **이유(h1 채택)**: 레포 관례 — 페이지 최상위 제목은 h1(mypage·my-plan·admin·payment 등), 카드·섹션은 h2. auth 카드 제목은 페이지 유일 제목이라 h1. 타이포는 400px 카드 안이라 페이지 h1 급(26~28px) 대신 mypage 카드 제목 급(text-lg font-bold tracking-[-0.01em]) 준용 — 시맨틱 레벨과 시각 크기는 별개.

### 결과
- **signup page.test 통과 전환** — heading '회원가입' 기대 충족 (테스트 무수정).
- `npm test`: 실패 2스위트/1테스트(lib/auth actions·SpotPopup) — 기존 실패 목록의 부분집합, 신규 실패 0. 0608 시점 6스위트/8테스트에서 auth 화면 재구성 3연작(0609~0611)을 거치며 signup·login 스위트 4벌이 전부 통과로 전환됨.

### 배운점
- "골격 정본 그대로 준용"은 화면 정체성 요소(제목)까지 지우면 과적용이 된다 — 형제 화면의 공통 골격과 화면별 구분 요소를 분리해서 준용 범위를 정할 것. 실패 중인 테스트가 그 구분 요소의 명세 역할을 하고 있었다.

## 결정 (Decisions)

- auth 화면 제목 = h1 (페이지 유일 제목 — 레포 관례: 페이지 h1 / 카드·섹션 h2). 시각은 mypage 카드 제목 급 준용.
- 태그라인 "여행의 시작점을 찍다." 제거 — 두 화면 공통 문구는 화면 구분에 기여하지 않음. 로고 "Dotrip"은 유지.
- theme.ts의 경고 축 주석 현행화는 미수행(범위 밖) — 색 토큰 정리 사이클(경고 축 4종 + success 축 판정, 0610 결정)에서 함께.
