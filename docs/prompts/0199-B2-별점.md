# 0199 회고: B2 별점 — StorySpot.rating과 평균 파생

작성일: 2026-07-14 / 소요: 약 1.5시간 / 커밋: 6576908

## 1. 한 줄 요약
별점을 per-visit(StorySpot)에 저장하고 Spot의 ★는 평균 파생으로 — 세 경로(로드·payload·저장)에 전부 실어 소실을 막았다.

## 2. 왜 / 목적 / 이유
- **왜**: 시안의 "★ 4.9 (12)" 자리가 비어 있었다.
- **목적**: StorySpot.rating(nullable Int 1~5) + 평균·개수 파생 + 우측 패널 4번째 칸(2×2 완성). 별점 없으면 셀 미렌더(★0.0 금지).
- **이유(자리)**: 별점은 "이 장소가 어떤가"가 아니라 "내가 다녀와서 어땠나" — per-visit. Spot.rating 단일 컬럼이면 마지막 사람이 덮어쓴다. CHECK 제약은 Prisma drift 때문에 미도입, 앱단 + clampRating 서버 방어. upsert update에 rating 포함(오입력 정정 가능해야 함).

## 3. 작성한 프롬프트
★★★★★ — DDL 사전 보고 + 0191 교훈(payload 스레딩)·0198 교훈(upsert update 목록) 관문 명시. rating이 Spot 컬럼이 아니라 재도출 derived로 흐르지 않음을 CC가 선제 발견 — payload spotId 맵으로 스레딩.

```ts
// lib/spot/rating.ts — 신설. 앱단 검증(SpotPopup zod)과 **이중화**.
// DB는 plain Int? 라 최종 정합은 여기서 보장.
export function clampRating(r: unknown): number | null {
  return typeof r === 'number' && Number.isInteger(r) && r >= 1 && r <= 5 ? r : null;
}
```

// lib/spot/queries.ts — 파생: rating 있는 방문만 집계(null 제외).
// 하나도 없으면 null → 우측 패널 별점 셀 미렌더 (0187이 비워둔 4번째 그리드 셀)
const ratings = storySpots.map((ss) => ss.rating).filter((r): r is number => r != null);
const ratingCount = ratings.length;
const rating = ratingCount > 0
  ? Math.round((ratings.reduce((a, b) => a + b, 0) / ratingCount) * 10) / 10  // 소수 1자리
  : null;

## 5. 결과 / 교훈
- 12파일. 격리 테스트: id 유지·4→3 갱신·취소(null)·범위 밖 clamp — 0198의 upsert가 rating을 실제로 지킴을 실증.
