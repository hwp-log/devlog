# 0186 회고: SpotFinder 우측 패널 — 이 장소의 작품·다녀온 이야기

작성일: 2026-07-13 / 소요: 약 1시간 / 커밋: 81229dc

## 1. 한 줄 요약
우측 패널에 메타 줄·작품 목록·다녀온 이야기 섹션을 추가하고, 출처 섹션을 제거했다.

## 2. 왜 / 목적 / 이유
- **왜**: 시안(B3)의 우측 패널이 미구현이었고, 기존 "출처"(단수 작성자)는 공유 스팟 구조와 충돌했다.
- **목적**: 작품 N편·스토리 N편 메타, 작품 목록(제목만), 이야기 발췌 카드.
- **이유**: 출처 제거 — 공유 스팟에서 출처는 단일 작성자로 표현되지 않고, 작성자는 이야기 카드에 이미 있어 같은 사실이 두 곳에 표시된다(§8②의 UI 버전). 작품 썸네일 제외 — 스팟 대표 썸네일 동일값이라 작품 2편이 같은 그림으로 나열되는 오정보.

## 3. 작성한 프롬프트
C2 프롬([하지 말 것]: B2 별점 플레이스홀더·스키마 변경·"1/4 촬영지·사진 12장"류 발명 금지) + 출처 제거 추가 지시(author·extraAuthorCount 미사용 확인 요구, queries 도출은 보존).
