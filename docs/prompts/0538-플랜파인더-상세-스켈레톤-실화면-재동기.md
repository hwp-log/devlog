## 1. 한 줄 요약

(초안 — 초안)

## 4. 코드 작성 & 수정

### 대조 결과 (13개 항목 중 11개 어긋남)

핵심 3가지: ① 폭 래퍼 부재(레이아웃 기본 분기 1232 vs 실화면 860) ② 히어로(200/300px)·지표 밴드·비용·항공 섹션 통째 누락 ③ 일정이 카드형(h-16 rounded-xl)인데 실화면은 행 목록(번호+60px 썸네일+hairline, 0513).

### loading.tsx 전면 재작성

`app/(protected)/plan-finder/[id]/loading.tsx` 1개 파일. 실화면 3파일(PlanFinderDetail / PublicCostSection / PublicFlightTable)의 폭·높이·마진 클래스를 그대로 준용, 각 블록에 짝 상호 참조 주석("한쪽만 바꾸면 시프트").

```tsx
// 폭: 실화면 래퍼와 동일 토큰(--reading-w = 860, 0534)
<div aria-hidden className="max-w-[var(--reading-w)] mx-auto">
  {/* 히어로 — h-200/300 rounded-[14px] mb-4 */}
  <div className="h-[200px] sm:h-[300px] rounded-[14px] mb-4 skeleton-shimmer" />
  {/* 메타 행(아바타→닉네임→날짜, 우측 액션) → 지표 밴드 3열(border-t/b) → 소개문 2줄 */}
  {/* 일정: 22px 헤더+2px 실선 → Day 탭 3개 → 행 4개(py-[13px]+60px 썸네일+hairline) */}
  {/* 비용: 총액 h-8 → 누적 막대 h-3 → 카테고리 2열 4칸 → 접기 헤더 2줄(접힘=제목 줄만) */}
  {/* 항공: 헤더 → 2행(sm 그리드 py-[15px], 모바일 스택) */}
```

**대표 개수**: Day 탭 3(2박3일 대표형) / 일정 행 4(첫 뷰포트 채움, 기존 유지) / 비용 카테고리 4(2열 조판이 드러나는 최소 짝수) / 접기 그룹 2(실화면 고정, 접힘) / 항공 2행(왕복 대표형). 조건부 섹션(커버·소개·비용·항공)은 "공개 플랜 대표형 = 전부 있음"으로 고정 — 스켈레톤은 데이터를 모르므로.

## 5. 결과 / 배운점

### 결과
- `npx tsc --noEmit` 통과. 폭 정렬선·히어로 높이·행 패딩이 실화면과 동조.
- 잔여 시프트: 조건부 요소 없는 플랜(커버 없음 등)에선 원리상 제거 불가 — 대표형 기준 수용.
- 드리프트 재발 방지: 구조 클래스 공용화(히어로 높이·행 py를 비클라이언트 공용 모듈로 추출해 양쪽 참조 — `--reading-w` 방식)가 근본 해법이나 실화면 무접촉 지시라 이번엔 상호 참조 주석까지만. **공용화는 별도 사이클 후보.**

## 결정 (Decisions)

- 스켈레톤 조건부 섹션은 "대표형 = 전부 있음"으로 고정 (데이터 미지 상태에서 분기 불가)
- 섹션 실선(border-section-rule)·hairline은 shimmer 없이 실색 즉시 표시 (구조선은 로딩 대상 아님)
