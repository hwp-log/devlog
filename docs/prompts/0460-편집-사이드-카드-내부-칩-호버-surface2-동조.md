**작성일**: 2026-08-01
**소요 시간**: 기록 없음
**관련 커밋**: fix: 0460 편집 사이드 카드 내부 칩·호버를 surface2 면에 동조 (e3f3813)

---

## 1. 한 줄 요약

0459의 편집 사이드 카드 면 승격(card→surface2)으로 카드면과 동색이 된 칩(수정·취소·닫기·뒤로·작품 칩)에 `border-border` 테두리를 추가하고, Δ0이 된 `hover:bg-surface2`를 `hover:bg-popover`로 교체 — 정지=테두리 / 호버=면 반응으로 상태 언어 복구.

---

## 2. 왜 / 목적 / 이유

(초안 — 검수·확정 과정에서 추린 초안 수준)

- **왜**: 실화면에서 스팟 팝업 "수정" 버튼이 안 보임(삭제는 빨간 테두리라 보임). 검수 결과 테두리가 안 보이는 게 아니라 **애초에 테두리가 없는 `bg-surface2` 칩**이었고, 종전 card 면(1.09:1) 위에서 면 차이로 보이던 것이 surface2 면에서 동색(1.00:1)이 되어 소멸.
- **목적**: 카드면의 읽기 정합(surface2, 0459)은 유지하면서 내부 상태 언어 복구.
- **이유(처방)**: 읽기 카드 SpotList 행(`bg-surface2`+border, 0377부터 수용된 선례)과 같은 "정지=테두리" 처방 — 수정 버튼이 삭제(`border-red-200`)와 대칭 회복. 색 추가 없음(상태 위계 원칙, 0267~0272).

### hover Δ 수치 보고 (사용자 요청 — 적용 없이 기록만)

`hover:bg-popover`의 surface2 면 위 반응은 채널당 Δ3~4(1.04~1.05:1) — 종전 카드면의 hover 반응(Δ10, 1.09~1.13)의 절반 수준. 단 읽기 카드(0377~)가 이미 쓰는 수용된 페어. 부족 시 후보: `bg-card`(1.09/1.13) · `bg-bg`(1.22/1.23) · `bg-bg-deep`(1.13/1.29). 다크는 surface2가 서피스 위계 최상단이라 모든 후보가 어두워지는(침하) 방향. **교체 여부는 육안 확인 후 별도 결정.**

## 결정 (Decisions)
- surface2 면 위 정지 상태 구분은 테두리(`border-border`), 호버는 면 반응(`hover:bg-popover`) — 읽기 카드 SpotList 행 선례를 편집 카드 전체로 확장
- `--border`는 알파 토큰이라 합성 대비(~1.22/1.28)가 면과 무관 — 면 승격 회귀 판정에서 테두리는 용의선상 제외 가능
- fill 스케일은 hover 면 용도 부적합 (0337 용도 규정: 눈썹·아이콘·차트 채움 한정)
