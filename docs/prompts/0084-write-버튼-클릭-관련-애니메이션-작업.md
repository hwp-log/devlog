# 0084 회고: write 버튼 클릭 관련 애니메이션 작업

작성일: 2026-06-10
소요: 1시간
관련 커밋: 1c6475de (feat: 0084 write 버튼 hover 거리 조정 및 스토리 카드 active 눌림 추가)

## 1. 한 줄 요약
Write 버튼의 hover 이동 거리를 키우고 스토리 카드에 누름(:active) 반응을 추가해, 클릭되는 요소의 행동 유도성과 피드백을 일관되게 다듬었다.

## 2. 왜 / 목적 / 이유

**왜 (동기/문제)**
0081에서 Write 버튼에 입체 모양과 hover 애니메이션을 넣었으나, hover 시 translate 이동 거리가 짧아 효과가 눈에 띄지 않았다. 넣은 피드백이 사용자에게 전달되지 않은 상태였다. 또한 스토리 카드는 클릭하면 상세로 이동하는 요소인데도 누름 반응이 없어 버튼과 피드백이 어긋났다.

**목적 (도달할 상태 / 사용자 가치)**
사용자가 누르고 싶게 만든다. 구체적으로 — 클릭 가능함을 분명히 보이고(행동 유도성, affordance: 요소가 "누를 수 있다"를 시각적으로 알리는 성질), 누름 반응을 명확히 보여 "눌렀다"는 확인을 준다. 버튼과 카드가 같은 물리 언어를 갖게 한다.

**이유 (채택 근거 / 의사결정)**
hover translate 거리를 키워 "누를 수 있다"는 예고 신호가 실제로 보이게 했다. 카드에 :active 눌림을 추가해 누르는 순간 "눌렀다"는 확인을 줬다. 결과적으로 클릭의 3단계 — 기본(rest) / hover(누르기 전 예고) / active(누르는 순간 확인) — 를 버튼과 카드 모두에 갖췄다.

## 5. 결과 / 배운점
- 결과: 버튼 hover 효과가 눈에 띄게 드러나고, 카드 누름 반응으로 버튼·카드의 클릭 피드백이 일관됐다.
- 배운점 1: "효과를 넣었다"와 "효과가 전달된다"는 다르다. hover를 넣었어도 이동 거리가 짧으면 사용자 눈에 닿지 않는다 — 인터랙션은 의도대로 전달되는지까지 확인해야 한다.
- 배운점 2: 클릭은 rest / hover / active 3단계 피드백으로 볼 수 있고, 클릭되는 모든 요소가 같은 단계를 갖춰야 경험이 일관된다. (카드 :active는 작업 당시 막연히 추가했으나, 회고에서 이 3단계 모델로 그 의미를 정리했다.)
