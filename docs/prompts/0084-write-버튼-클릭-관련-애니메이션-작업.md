# 0084 회고: write 버튼 클릭 관련 애니메이션 작업

작성일: 2026-06-10
소요: 1시간
관련 커밋: 1c6475de (feat: 0084 write 버튼 hover 거리 조정 및 스토리 카드 active 눌림 추가)

## 1. 한 줄 요약
Write 버튼의 hover 이동 거리와 트랜지션 시간을 키우고, 카드에 누름(:active) 반응을 추가해, 클릭되는 요소의 행동 유도성과 피드백을 일관되게 다듬었다.

## 2. 왜 / 목적 / 이유

**왜 (동기/문제)**
0081에서 Write 버튼에 입체 모양과 hover 애니메이션을 넣었으나, hover 시 이동 거리가 짧아(-1px) 효과가 눈에 띄지 않았다. 넣은 피드백이 사용자에게 전달되지 않은 상태였다. 또한 스토리 카드는 클릭하면 상세로 이동하는 요소인데도 누름 반응이 없어 버튼과 피드백이 어긋났다.

**목적 (도달할 상태 / 사용자 가치)**
사용자가 누르고 싶게 만든다. 구체적으로 — 클릭 가능함을 분명히 보이고(행동 유도성, affordance: 요소가 "누를 수 있다"를 시각적으로 알리는 성질), 누름 반응을 명확히 보여 "눌렀다"는 확인을 준다. 버튼과 카드가 같은 물리 언어를 갖게 한다.

**이유 (채택 근거 / 의사결정)**
버튼은 hover 이동 거리를 -1px에서 -3px로 키우고 트랜지션 시간을 .25s에서 .55s로 늘려, "누를 수 있다"는 예고 신호가 실제로 눈에 들어오게 했다(거리와 시간을 함께 키운 것). 카드에는 `:active` 눌림을 추가해 누르는 순간 "눌렀다"는 확인을 줬다. 결과적으로 클릭의 3단계 — 기본(rest) / hover(누르기 전 예고) / active(누르는 순간 확인) — 를 버튼과 카드 모두에 갖췄다.

## 3. 작성한 프롬프트
프롬프트 기록이 없어 생략한다. (직접 코드를 조정한 작업.)

## 4. 코드 작성 & 수정

```css
/* app/globals.css */

/* Write 버튼: hover 시 뜨는 거리와 시간을 키워 효과가 눈에 들어오게 */
.btn-elevated {
  /* 변경 전: transition ...25s / 변경 후: .55s (효과가 더 천천히, 분명하게 드러남) */
  transition: transform .55s cubic-bezier(0.4, 0, 0.2, 1),
              box-shadow .55s cubic-bezier(0.4, 0, 0.2, 1);
}

.btn-elevated:hover {
  transform: translateY(-3px); /* 변경 전 -1px → -3px (뜨는 거리 키움) */
  /* box-shadow ... */
}

/* 카드: hover로 떠오른 상태에서 누르면 살짝 내려앉아 "눌림"을 표현 */
.glass-outer-interactive:hover {
  transform: translateY(-8px) scale(1.03);   /* 떠오름 (예고) */
}

.glass-outer-interactive:hover:active {
  transform: translateY(-5px) scale(1.01);   /* 누르면 내려앉음 (확인) */
  transition-duration: .12s;                  /* 빠르게 — 누름은 즉각 반응해야 자연스러움 */
}
```

핵심:
- `btn-elevated`는 hover 거리(-1px → -3px)와 시간(.25s → .55s)을 함께 키워, "거리가 짧아 안 보이던" 효과를 실제로 드러냈다.
- 카드의 `:hover:active` — hover로 -8px 떠오른 상태에서 누르면 -5px로 내려앉는다. "들렸다(hover) → 눌렸다(active)"가 한 동작으로 이어지는, 물리 버튼을 누르는 느낌. 누름 반응의 transition은 .12s로 즉각이다(예고는 천천히, 확인은 즉각).

## 5. 결과 / 배운점
- 결과: 버튼 hover 효과가 눈에 띄게 드러나고, 카드 누름 반응으로 버튼·카드의 클릭 피드백이 일관됐다.
- 배운점 1: "효과를 넣었다"와 "효과가 전달된다"는 다르다. hover를 넣었어도 이동 거리(-1px)나 시간이 부족하면 사용자 눈에 닿지 않는다 — 거리(-3px)와 시간(.55s)을 함께 키워 전달되게 했다. 인터랙션은 의도대로 전달되는지까지 확인해야 한다.
- 배운점 2: 클릭은 rest / hover / active 3단계 피드백으로 볼 수 있고, 클릭되는 모든 요소가 같은 단계를 갖춰야 경험이 일관된다. 특히 누름 반응(active)의 트랜지션은 빠르게(.12s) 둬야 즉각적인 확인 느낌이 난다 — 예고(hover)는 천천히, 확인(active)은 즉각. (카드 :active는 작업 당시 막연히 추가했으나, 회고에서 이 3단계 모델로 그 의미를 정리했다.)
- 배운점 3: 이때 만든 `.glass-outer-interactive`의 hover/active 정의를 0087 My Plan 카드가 그대로 재사용한다. 인터랙션 규칙을 한 곳에 정의해두면 버튼·카드 등 클릭되는 요소들이 모두 같은 반응(올리면 뜨고, 누르면 내려앉음)을 보여, 사용자가 한 번 익힌 조작감이 어디서나 통한다.
