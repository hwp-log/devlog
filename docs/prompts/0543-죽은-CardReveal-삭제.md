- docs - 0543 §11 등장 연출 금지 한 줄 - 스켈레톤 화면의 콘텐츠는 무연출 (5507f18)

---

## 1. 한 줄 요약

/story 목록의 CardReveal 미재생을 조사한 결과 사용처가 이미 0307에서 제거돼 있었고, 0542 이후 소비자가 0이 된 CardReveal.tsx와 전용 훅 use-in-view-once.ts를 삭제 + "스켈레톤 화면의 콘텐츠 등장 연출 금지"를 §11에 명문화.

---

## 2. 왜 / 목적 / 이유

(초안 — 초안)

- **왜**: 실화면에서 /story 카드 순차 등장이 재생되지 않음을 확인 — 죽은 코드로 의심.
- **조사 결론**: 조건 미충족이 아니라 호출 자체가 없음. StoryCardList는 0307(크로스페이드 전환) 때 CardReveal을 걷어냈고, 죽은 것은 사용처가 아니라 **컴포넌트 자체**(0542에서 마지막 소비자 MyPlan·MyStory 제거로 고아화).

---

- 삭제: `story/_components/CardReveal.tsx`(71줄 중 39) + `lib/use-in-view-once.ts` — 전역 grep으로 소비자 0 확인(남은 매칭은 전부 주석 언급), tsc로 잔여 참조 0 검증. 실화면 무접촉.
