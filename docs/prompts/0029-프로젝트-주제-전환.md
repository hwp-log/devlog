## 2. 왜 / 목적 / 이유

### 프로젝트 주제 전환
- **왜**: DevLog는 개인 학습 기록 대시보드였으나, '한국 콘텐츠 촬영지 탐방·기록·여행계획 플랫폼'으로 주제를 전환.
- **목적**: 코드베이스(app/ / lib/)는 그대로 두고, 주제 관련 문서·메타 파일만 교체해 전환 비용 최소화.
- **이유**: TIL 라우팅·테이블·컴포넌트 이름 변경은 다음 작업 스코프. 이번은 "DevLog 흔적 제거 + Dotrip 선언"만.

### 전환 근거
- VELTRA·JTB·KONEST 등 일본 여행사가 K-드라마 투어 패키지 판매 중 = 수요 존재 증명.
- 촬영지 기록 플랫폼 = 작성자·소비자 국적 제한 없음. MVP는 방한 K-콘텐츠 팬덤 타깃.
