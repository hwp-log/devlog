- 작성일: 2026-06-24

## 1. 한 줄 요약

작성자 아바타를 이모지로 세 번 시도했으나, 이모지는 작성자 식별이 안 되는 본질적 한계가 있어 "닉네임 첫 글자 + 해시 색" 이니셜 블록으로 안착했다. 함께 순위 배지를 제거해, 인기 글 쏠림으로 코스가 획일화되는 것을 완화했다.

## 2. 왜 / 목적 / 이유

### 아바타 — 이모지에서 이니셜 블록으로

- 왜: 작성자 아바타를 fun-emoji → Twemoji 사람 표정 순으로 세 번 시도했으나 계속 어울리지 않았다. 처음엔 개별 이모지 문제로 봤지만, 더 근본적으로 이모지는 작성자 식별이 안 됐다. 랜덤 이모지는 닉네임과 연결이 없어, 누가 썼는지·다른 작성자와 어떻게 다른지 구분되지 않았다.
- 목적: 작성자를 한눈에 식별할 수 있고, Dotrip의 정돈된 톤과 통일감을 해치지 않는 아바타.
- 이유:
  1. 아바타의 본질은 작성자 식별이다. 이니셜 블록(닉네임 첫 글자)은 작성자와 직접 연결되고, 색을 닉네임 해시로 deterministic하게 정하면 같은 작성자는 항상 같은 글자·같은 색으로 나온다. (실제로 같은 작성자의 두 코스가 같은 "술" + 같은 스카이블루로 표시돼 동일인임이 바로 읽힌다.)
  2. 꾸미기(안경·모자 등 커스텀)도 검토했으나, 화면마다 제각각이 돼 UI 통일성을 해친다. 정해진 8색 팔레트 안에서만 도는 방식이 다양성과 일관성을 동시에 만족한다.
  3. 이니셜 블록은 GitHub·노션·슬랙이 쓰는 업계 표준이며 외부 의존이 0이다(이모지 CDN·SVG 파일 불필요).
  - 이모지 세 번 시도는, "어떤 이모지가 나은가"가 아니라 "이모지라는 형식 자체가 답이 아니다"를 확인한 과정이었다. 시행착오로 문제를 다시 정의했다.

### 순위 배지 제거 — 1등 쏠림과 획일화 완화

- 왜: 카드 말풍선에 순위 배지(1·2·3)를 달았는데, 좋아요 수가 이미 보이는 상태에서 명시적 순위까지 붙으면 사람들이 1등 글만 보게 된다.
- 목적: 사용자가 특정 1등 코스에 쏠리지 않고 여러 코스를 고르게 둘러보는 상태.
- 이유: 좋아요 + 순위가 겹치면 상위 글에 조회·모방이 집중되고, 다들 1등 코스를 따라 만들어 비슷한 코스가 양산된다. PlanFinder는 "다양한 여행 코스를 둘러보는 곳"이지 "등수를 매기는 곳"이 아니다. 인기순 정렬은 참고용으로 유지하되(정렬 로직 그대로), "등수"라는 못은 박지 않아 1등 쏠림을 완화하고 덜 알려진 코스도 보이게 했다. 여행 코스에 경쟁 프레임을 씌우지 않으려는 의도이기도 하다.

## 4. 코드 작성 & 수정

### 이니셜 + 해시 색 (deterministic)

```ts
// lib/avatar/generate.ts
const PALETTE = ['#0EA5E9','#14B8A6','#6366F1','#F97362',
                 '#F5A623','#EC8FB0','#34D399','#A78BFA']; // 8색

export function getAvatarInfo(nickname: string) {
  const initial = nickname[0] ?? '?';
  let sum = 0;
  for (let i = 0; i < nickname.length; i++) sum += nickname.charCodeAt(i);
  const color = PALETTE[sum % PALETTE.length]; // 닉네임 해시 → 같은 닉네임은 항상 같은 색
  return { initial, color };
}
```

### 말풍선 아바타 (이미지 태그 제거 → 글자 블록)

```tsx
// PlanCard.tsx
const { initial, color } = getAvatarInfo(authorNickname);
// 말풍선: border-radius 18px 18px 18px 4px (좌하단 꼬리), 배경 = color
// 안에 흰색 굵은 첫 글자 (text-2xl). <img> 제거.
```

### 순위 제거 (rank prop 4곳 정리)


## 5. 결과 / 배운점

- 같은 작성자의 두 코스가 같은 글자("술")·같은 색(스카이블루)으로 표시돼 동일인임이 바로 읽힌다. 순위 배지가 사라져 카드가 깔끔해지고, 인기순 정렬은 그대로 동작한다. (tsc 통과, grep rank 0건 확인.)
- 아바타의 본질은 식별: 보기 좋은가보다 "작성자를 구분할 수 있는가"가 먼저다. 랜덤 이모지는 닉네임과 연결이 없어 이 본질을 충족하지 못했다. 이니셜 + 해시 색은 deterministic해서 같은 작성자를 항상 같게 표시한다.
- 시행착오로 문제를 다시 정의: 이모지를 세 번 갈아엎고서야 "개별 이모지 선택"이 아니라 "이모지라는 형식"이 문제임을 확인했다. 단, 디테일에 세 번 매달린 것은 경계할 지점이기도 하다(핵심 기능·지원이 우선).
- 표시가 행동을 만든다: 순위 배지는 단순 장식이 아니라 사용자 행동(1등 쏠림)과 콘텐츠 생태계(코스 획일화)에 영향을 준다. 무엇을 보여줄지가 무엇을 따라 하게 만들지를 결정한다. 정렬은 참고로 두되 "등수"는 박지 않는 선택.
- 자유도와 일관성: 꾸미기 커스텀은 표현 자유도를 주지만 화면 통일성을 해친다. 정해진 팔레트 안의 deterministic 방식으로 둘을 동시에 만족시켰다.
