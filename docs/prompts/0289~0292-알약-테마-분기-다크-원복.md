# 0289~0292 회고: 라벨 마커 라이트 평탄화·색 통일 — isDark 분기 확정

**작성일**: 2026-07-20
**관련 커밋**: `bd7faf6` style: 0292 라벨 마커 라이트 평탄화·색 통일 - 비선택 회색·hover 회색·선택 플랫, 다크 무변

## 1. 한 줄 요약

알약(pill)의 색·그림자를 인라인 var() 토큰 페어(0289~0291)에서 `markerContent(spot, selected, isDark)` JS 분기로 전환 — 다크는 0269~0270 확정 리터럴을 바이트 그대로 원복(입체감 복원), 라이트는 비선택 = card 단색 + border 토큰 얇은 테두리 / 선택 = primary 단색·그림자 없음의 완전 플랫. 소비처가 사라진 pill·sel 토큰 6종은 theme.ts에서 정리(hover 4쌍은 globals.css 소비라 유지).

## 2. 왜 / 목적 / 이유

- **왜**: 0291 후 3가지 문제 — ① 다크 알약까지 평탄하게 보임(다크는 입체감이 정본) ② 라이트 회색 알약이 지도에 묻힘(경계 없음) ③ 라이트 파란 선택 알약에 그라데이션 광택(입체) 잔존. [사용자 확인 필요]
- **목적**: 다크 원복(최우선) + 라이트 알약 완전 플랫 + 비선택 경계 확보.
- **이유**: 정적 확증(토큰 발행·컴파일 CSS·다크 스코프 전수)으로는 다크 평탄화 경로를 재현 못 했으나 실기기 관측이 우선 — 인라인 var() 의존을 제거하고 값을 문자열로 직접 박는 JS 분기가 이 계열 불확실성을 구조적으로 차단. 테마 전환 = 지도 재생성(0284)이라 마커가 항상 최신 테마로 리빌드돼 분기 안전. ③은 배경 자체(color-mix 그라데이션)가 광택이라 그림자 제거만으론 부족 — 라이트는 단색 primary로.

## 3. 작성한 프롬프트 (4소작업 — 반복 이력)

이 회고는 네 번의 프롬프트(0289~0292)가 미커밋 상태로 값을 뒤엎으며 수렴한 과정을 한 편으로 묶는다. 코드는 최종 상태(0292 isDark 분기) 기준, 아래는 도달 경로.

- **0289 (비선택 알약 칩 통일)**: 비선택 알약 라이트 색을 검색바·칩(0287)과 통일 — 그라데이션 아래 스톱을 공용 surface2에서 전용 `markerPillLo`로 분리, 라이트 hi=lo=card 평면 + 테두리 transparent. (인라인 var() 토큰 페어 접근의 시작)
- **0290 (hover 정정·선택 평탄화)**: 0289 평면화 후 hover가 다크 값으로 튐 → hover 토큰 라이트를 회색 평면(#e8e8ee)으로, 선택 그림자를 토큰 쌍으로 분리해 얕게.
- **0291 (알약 완전 평탄화)**: 비선택 그림자도 토큰(`markerPillShadow`)으로 분리, 선택 그림자 none — 알약 전체 플랫.
- **0292 (다크 원복·최종 확정)**: 0291 후 실기기에서 다크 알약까지 평탄해짐(다크는 입체가 정본). 인라인 var() 페어로는 다크 평탄화가 정적 재현 안 돼 불확실 → **접근 자체를 JS 분기로 전환**, 다크는 0269 리터럴 바이트 원복.

### 1. `components/SpotFinderMapNaver.tsx` — markerContent isDark 분기

```ts
function markerContent(spot: SpotFinderSpot, selected: boolean, isDark: boolean): string {
  // 선택 점 꼬리 그림자도 분기 (파랑 발광 링·핑은 양 테마 유지 — 선택 신호)
  const dotShadow = selected
    ? `..., ${isDark ? '0 2px 6px rgba(0,0,0,0.5)' : '0 1px 2px rgba(25,26,28,0.15)'}`
    : '0 2px 6px rgba(0,0,0,0.5)';
  const pillColor = selected
    ? (isDark
      ? `...color-mix 그라데이션 + inset 광택 + 검정 그림자...`   // 0269 원본 리터럴 바이트 원복
      : `background:${PRIMARY};color:#fff;border:1px solid ${PRIMARY};box-shadow:none;`)  // 완전 플랫
    : (isDark
      ? '...#33383d 그라데이션 + 흰 0.5 테두리 + inset + 검정 그림자...'  // 0269 원본 리터럴 바이트 원복
      : 'background:var(--card);color:var(--fg2);border:1px solid var(--border);box-shadow:none;');  // 플랫 + 얇은 테두리
```

  테마 전환 시 지도 재생성(0284)으로 마커 effect가 재실행돼 최신 테마 리빌드.

## 결정 (Decisions)

- **알약 본체 색·그림자 = markerContent(isDark) JS 분기** — 인라인 var() 페어(0284 이래 관례)를 알약에 한해 폐기. 근거: 실기기에서 다크 평탄화 관측(정적 재현 불가), 값 직접 주입이 불확실성을 구조적으로 차단 + 테마 전환마다 마커 리빌드(0284 지도 재생성)라 분기 안전. **hover는 var() 유지** — globals.css 클래스 경로는 정상 동작 확인.
- **라이트 알약 언어 확정**: 비선택 = card 단색 + border 토큰 1px(지도 위 경계) / 선택 = primary 단색 / 그림자 0. 다크 = 0269 확정 리터럴(그라데이션·광택·그림자) 보존 — 테마별로 재질 언어가 다름(라이트 플랫 vs 다크 입체)을 공식화.
- 인라인 var()와 JS 분기의 선택 기준(0284 결정 갱신): 값이 실기기에서 확실히 해석되는 경로(CSS 클래스)는 토큰, 서드파티 DOM 주입 인라인은 JS 분기.
