## 4. 코드 작성 & 수정

### 1. `app/(protected)/_components/ThemeToggle.tsx` — 트랙 스위치로 재작성

```tsx
<button type="button" aria-label="테마 전환" onClick={handleToggle}
  className="relative h-[28px] w-[52px] shrink-0 rounded-full bg-surface2 dark:bg-primary
    transition-colors duration-[250ms] ease-[cubic-bezier(0.25,0.1,0.25,1)]
    before:absolute before:-inset-2 before:content-['']">
  <span aria-hidden className="absolute left-[2px] top-[2px] flex h-6 w-6 items-center justify-center
    rounded-full bg-white shadow-sm transition-transform duration-[250ms] ease-[...] dark:translate-x-6">
    <Sun size={14} className="text-fg2 dark:hidden" />
    <Moon size={14} className="hidden text-primary dark:block" />
  </span>
</button>
```

- 트랙 라이트 #e8e8ee = **surface2 토큰 정합**(리터럴 대신 bg-surface2), 다크 = dark:bg-primary.
- knob 이동 24px = 52 − 24 − 2×2 (translate-x-6). 아이콘·트랙·knob 위치 전부 **CSS dark: variant 분기** —
  마크업이 테마 무관이라 mounted 가드 불필요(0283 원칙), useTheme은 onClick에서만.
- §5 대응: 시각 52×28은 44px 미달 → `before:-inset-2` 의사요소로 히트 68×44 확보(레이아웃 무영향).
- `ease-[ease]`는 Tailwind 미생성(0287 실측)이라 처음부터 등가 베지어로 작성.

## 결정 (Decisions)

- **테마 토글 위치 = 헤더 상시 노출 트랙 스위치** (0283의 드롭다운 항목 결정을 대체). 드롭다운엔 남기지 않음(단일 진입점).
- 스위치 상태 표현도 **CSS dark: variant 분기** — 트랙 색·knob 위치·아이콘 3요소 모두 마크업 무분기(0283 하이드레이션 원칙의 확장 적용, mounted 가드 대안 기각).
- 시각 스펙(52×28)과 §5 히트(44px)의 충돌은 **before 의사요소 히트 확장**으로 해소 — 시각 무영향 패턴.
