## 2. 왜 / 목적 / 이유

- **왜**: 0609가 auth 레이아웃의 사진 배경·스크림을 걷어내자 /signup 좌측 brand-side 패널의 `color:#FFFFFF` 하드코딩 글자가 라이트 토큰 배경 위 흰 글씨가 됨 — 0609가 만든 회귀. 그리드도 인라인 style이라 0607 모바일 1열 스택 수정조차 미적용 상태였다.
- **목적**: 0609에서 확정한 판단을 그대로 적용 — 새 판단 없이 /login을 골격 정본으로 준용.
- **일본어 병기 제거 이유**: 서비스 전체가 한국어이고 다국어 지원이 없어 그 화면만 병기되면 어긋남 (사용자 지시). /login엔 일본어 잔여 0건 확인(0609에서 brand-side 통째 제거됨).

## 결정 (Decisions)

- /signup 골격 = /login(0609) 정본 준용 — 카드 폭·로고·태그라인·하단 링크 동기 (상호 참조 주석).
