## 1. 한 줄 요약

카테고리 롤업(비중 막대)만 보이던 예상비용에 **PlanCost 행 그대로의 항목별 목록**을 붙이고(0498),
그 목록을 금액순 평면 나열에서 **일자별 그룹**으로 재구성했다(0499).

---

## 2. 왜 / 목적 / 이유

- 왜 카테고리 요약만으로 부족했는지
- 왜 그룹 안 정렬은 금액 내림차순을 유지하고 그룹 자체만 날짜 오름차순으로 했는지
  (주석에 "within-day A안"이라는 선택지 표기가 남아 있음 — B안이 무엇이었는지 기록 없음)

---

## 3. 작성한 프롬프트

기록 없음.

주석에 남은 흔적: 0499에 "0499 Q1"(항공 머리글 그룹을 Day 머리글과 평행 구조로 둘지),
"within-day A안"(날짜 안 정렬) — 선택지를 두고 컨펌한 흐름은 확인되나 문면은 없음.

### 0499 — 일자별 그룹

**계약 교체** — `items` → `itemGroups`:
```ts
// 0499: 항목 단위 상세를 일자별 그룹으로 묶음. 항공(dayless)은 day=null 그룹으로 맨 위.
// 비용 있는 날만 오름차순, 날짜 안은 금액 내림차순(0498 정렬 유지). PlanCost 행 그대로(롤업 X).
itemGroups: Array<{
  day: number | null;  // null = 항공(합성, day 없음) → 목록 맨 위
  label: string;       // '항공' | `Day ${day}`
  items: Array<{ label: string; category: CostCategory | 'FLIGHT'; amount: number }>;
}>;
```

**그룹핑** — 존재하는 행에서만 파생:
```ts
// 0499: 일자별 그룹핑. 존재하는 PlanCost 행에서만 파생 → 비용 없는 날은 그룹 자체가 안 생김(머리글 생략).
const day = c.day ?? 0; // 방어: day 미select 소비처(band 전용)는 0 버킷 — itemGroups 미렌더라 무해
```
```ts
// 비용 있는 날만 오름차순, 날짜 안은 금액 내림차순(0498 정렬 유지 = within-day A안)
...[...dayBuckets.keys()].sort((a, b) => a - b)
  .map((day) => ({ day, label: `Day ${day}`, items: dayBuckets.get(day)!.sort((a, b) => b.amount - a.amount) })),
```

**표시**: 그룹 머리글(11px uppercase) + 항목 행 반복, `gap-3`로 그룹 간격.

**조회**: costs select에 `day: true` 추가.

## 5. 결과 / 실측

- 항목 개수 상한 근거(0498 주석): "접기 없이 전부(플랜당 최대 6)" — 이 시점 기준.
- 방어 로직: `day` 미select 소비처(story 3곳, band만 사용)는 0 버킷으로 모이되 `itemGroups`를
  렌더하지 않아 무해.

### 이후 사이클 (사실 기록)

- 0498의 "접기 없이 전부"는 **0507에서 기본 접힘으로 전환**(트랙 6).
- 0499의 `Day N` 라벨은 **0505에서 실날짜+요일로 교체**(트랙 6).
- 0499의 "PlanCost 행 그대로(롤업 X)" 평면 나열은 **0563에서 장소 단위 재구조화로 폐기** —
  현재 `summarize-plan-cost.ts` 주석: "구 '행 그대로(0499)'는 금액순 평면 나열이라 같은 장소
  지출이 흩어졌다". `itemGroups`는 day=null 전용으로 축소되고 `dayGroups`가 신설됨.
