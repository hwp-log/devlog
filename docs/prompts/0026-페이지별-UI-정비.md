## 한 줄 요약

기존에는 기능중심으로 코드를 작성하였기에, 페이지별 연동성이 없었음.
(예시: 로그인 이후 -> TIL 글을 작성하려면 -> https://devlog-hazel-eight.vercel.app/TIL -> 이런식으로 주소를 입력해야 했음.)

또한 연동성이 없다보니 이에 맞는 일관성이 있는 UI가 갖춰지지 않았음.

이를 해결하기 위해 이전 PRD에서 기획한 글을 참고하여, 페이지별 UI 정비를 시작.

PRD글 주소: https://hwp-log.github.io/techstory/techstory/prd/

## 이번 작업의 1가지 핵심 요소

### 1. 페이지별 기본 디자인 통일

**목적**

각 페이지를 따로 만들어왔기 때문에 색감, 여백, 카드 모양, 버튼 스타일이 달랐음.
사용자가 페이지를 이동할 때마다 "다른 사이트에 들어온 느낌"이 생기는 문제.
하나의 서비스로 인식되도록 전체 페이지 기본 디자인을 통일시킴.

**고민 — 어떻게 풀까?**

[케이스 A] 디자인 시스템(토큰)을 먼저 도입하고 전체 교체
1. @theme inline으로 색상 토큰을 먼저 정의.
2. 모든 페이지의 색을 토큰으로 일괄 변경.
3. 추후 색 변경 시 토큰만 수정.
4. 그러나 현재 단계는 디자인 자체가 확정 안 됨. 토큰을 잡으면 그 토큰에 갇힘.

[케이스 B] 페이지별로 같은 패턴을 직접 잡으면서 기본 디자인 통일
1. slate 계열 색상을 직접 사용.
2. 카드/버튼/간격 패턴을 같은 형태로 적용.
3. 디자인 시스템은 나중에 정착되면 도입.
4. 지금 단계에서 가장 빠르게 통일 가능.

[결론]
0023~24 DECISIONS.md에서 이미 "색상 토큰 미도입" 결정을 정한 상태.
현재는 기본 디자인 구축단계. [케이스 B]로 진행.
디자인 시스템 정립은 차후 고민후, 진행.

**방법**

- 색상 팔레트: slate 계열 직접 사용 (slate-50/100/300/600/800)
- 카드: 둥근 모서리 + 미세한 그림자 + slate-200 테두리
- 버튼: 주요(slate-800 배경) / 보조(slate-200 배경) / 위험(red-100 배경) 3종으로 통일
- 간격: 페이지 컨테이너 max-w-2xl, 요소 간 gap-4/gap-6
- 폰트: 제목 font-bold + 본문 slate-600

**기술 적용**

- 7개 페이지 (메인 / 로그인 / 회원가입 / 대시보드 / TIL 게시판 / TIL 상세 / TIL 작성) 일괄 적용
- Tailwind 유틸리티 클래스 직접 사용 (커스텀 CSS 추가 X)
- globals.css에는 @custom-variant 4개만 유지 (0024에서 추가한 것)
- 컴포넌트별 인라인 스타일 X, 모두 Tailwind로 작성

> **Tailwind 유틸리티 클래스**
> 미리 정의된 작은 클래스 조합으로 스타일 적용.
> 클래스 이름만으로 어떤 스타일이 적용됐는지 추론 가능.

> **@custom-variant**
> Tailwind v4에서 다크모드 같은 변형 상태를 직접 정의하는 기능.
> 0024에서 추가한 dark/hover/focus/disabled 4개를 그대로 사용.

**배운점**: 디자인 시스템을 잡는 시점과 기본 디자인을 잡는 시점은 다름.
기본 디자인이 먼저 잡혀야 토큰이 의미를 가짐.
토큰 없이 직접 색을 쓰는 게 추상화가 부족한 게 아니라, 단계가 다른 것.
"왜 토큰을 안 썼는가"의 답은 "쓸 시점이 아니기 때문".

## 코드 변화 (실제 결과물)

### 1. 색상 팔레트 통일 (7개 페이지 일괄)

```typescript
// 전체 페이지에서 slate 계열 직접 사용

// 배경
className="bg-slate-50"   // 페이지 배경
className="bg-white"      // 카드 배경

// 테두리
className="border-slate-200"

// 텍스트
className="text-slate-800"  // 제목
className="text-slate-600"  // 본문
className="text-slate-400"  // 부가 정보 (날짜 등)
```

### 2. 카드 공통 패턴

```typescript
// 카드 공통 클래스
className="rounded-lg border border-slate-200 bg-white p-4"

// 또는 그림자 적용
className="bg-white rounded-xl shadow-sm p-5"
```

### 3. 버튼 스타일 통일 (3종)

```typescript
// 주요 버튼 (저장, 작성 등)
className="bg-slate-800 text-white rounded-lg px-4 py-2"

// 보조 버튼 (취소 등)
className="bg-slate-200 text-slate-700 rounded-lg px-4 py-2"

// 위험 버튼 (삭제 등)
className="bg-red-100 text-red-700 rounded-lg px-4 py-2"
```

### 4. 간격 / 컨테이너 통일

```typescript
// 페이지 컨테이너
className="flex flex-col gap-6 max-w-2xl"

// 요소 간 간격
className="flex flex-col gap-4"
```

### 5. 비로그인 페이지 레이아웃 (메인 / 로그인 / 회원가입)

```typescript
// 중앙 정렬 + 카드 형태
<div className="min-h-screen bg-slate-50 flex items-center justify-center px-6">
  <div className="w-full max-w-md rounded-lg border border-slate-200 bg-white p-8">
    {/* 페이지 콘텐츠 */}
  </div>
</div>
```
