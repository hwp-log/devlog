# 0193 회고: 좌표 기반 커버 사진 — 18/45

작성일: 2026-07-14 / 소요: 약 1.5시간 / 커밋: 6c7289a

## 1. 한 줄 요약
KorService2 위치기반 조회로 커버 사진을 채우되, title 매칭 게이트로 "좌표 45m의 식당 사진"을 걸렀다 — Spot.coverUrl 신설.

## 2. 왜 / 목적 / 이유
- **왜**: 시딩 45곳의 썸네일이 회색 박스였다. PhotoGallery(이름 검색)는 실측에서 수원 화성→만석공원, 백운시장→진고개(홍천) 오매칭 — 절반이 틀린 사진.
- **목적**: 좌표(radius 1km) → title 매칭(완전·이름·핵심토큰 ≤300m) → https 치환 → 저장. 정확한 40%가 부정확한 75%보다 낫다.
- **이유(coverUrl 신설)**: photoUrl은 S4 제거 대상 구컬럼이자 per-visit(사용자가 다녀와 찍은 것). coverUrl은 per-place(외부 대표 사진) — 다른 사실을 한 컬럼에 겹치면 출처가 사라진다. 폴백 체인 `스토리 사진 ?? coverUrl ?? null`로 사용자 사진이 이긴다.

## 3. 작성한 프롬프트
실측 선행(샘플 10곳·radius 근거·키 방식·URL 형태) → 승인 시 300m 거리 게이트("수원 45m 모나미 카레를 버리는 게 이 게이트의 존재 이유") + 광역일치(부암동→동네 사진) 폐기.

function grade(name: string, title: string): number {
  const nN = norm(name), nT = norm(title), tok = norm(name.split(/\s+/)[0]);
  if (nT === nN) return 3;

  if (nN.includes(nT) && nT.length >= 2 && nT !== tok) return 2;
