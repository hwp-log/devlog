## 1. 한 줄 요약

인증 페이지 (로그인 / 회원가입) + 랜딩 페이지에 Apple Liquid Glass 시스템 적용.

---

## 2. 목적 / 이유

### a) 디자인 우선 작업 진입
- **목적**: UI 작업으로 주제에 맞는 디자인 컨셉 반영.
- **이유**: DevLog → Dotrip 주제 전환(0029) 이후 코드 자산 가져가기로 결정, 이에 따른 디자인 적용이 필요.

### b) 좌우 분할 카드 통일
- **목적**: 3페이지(랜딩 / 로그인 / 회원가입) 시각 통일 / UX 일관성.
- **이유**: 사용자 흐름 (= 랜딩 → 인증 → 대시보드)에서 페이지 UI가 통일돼야 UX 단절이 없음.

### c) 흰 글래스 우측 폼 영역
- **목적**: 좌측 brand-side (어두운 글래스 + 흰 텍스트) + 우측 form-side (흰 글래스 + 검정 텍스트).
- **이유**: 입력 필드 가독성이 인증 페이지의 핵심. 어두운 글래스 위에서 텍스트 입력은 불가.

### d) 글래스 wrapper 추출 보류
- **목적**: 코드 중복 vs 조기 추상화 트레이드오프 판단.
- **이유**: 사용처 2곳 / 배경이 임시 placeholder / 3차 리팩토링 시점에 추출 가치 재검토.

## 5. 결과 / 배운점

### 결과
- 인증 페이지 좌우 분할 카드 구조 완성 (로그인 / 회원가입).
- 폼 스타일 (입력 필드 0.5px border / rounded-full 버튼) 시안 매칭.
- 랜딩 페이지 = 인증 페이지와 시각 통일 / 3페이지 단일 글래스 카드 구조.
- 실제 배경 사진 적용으로 글래스 blur 효과 시각 확인 가능.

### 배운점
- **예쁜 것만이 우선은 아님.**: 좌우 분할 / 좌우 글래스를 적용해 보았으나.. 텍스트 가독성이 떨어지는 것을 확인. 그래서 우측 버튼, 입력영역은 단색배경으로 적용함.

---

## 결정 (Decisions)

- **좌우 분할 통일**: 청사진 1번 페이지(단일 카드)를 좌우 분할로 변형. 3페이지(랜딩 / 로그인 / 회원가입) 시각 통일을 위함.
- **흰 글래스 우측 폼**: 입력 가독성을 우선해 우측만 rgba(255,255,255,0.85) / 좌측은 어두운 글래스 상속.
- **글래스 wrapper 추출 보류**: 사용처 2곳 / 배경 임시 placeholder / 조기 추상화로 3차 리팩토링 시점에 재검토.
