## 1. 한 줄 요약
자동 매칭이 못 찾은 곳을 "기계가 후보를 뽑고 사람이 y/n" 방식으로 6곳 회복했다 — 등록명이 스팟명과 다른 케이스는 사람만 잇는다.

## 2. 왜 / 목적 / 이유
- **왜**: "북촌로6길"은 관광공사에 "북촌한옥마을"로 등록 — 검색어가 달라 자동으로는 영원히 못 찾는다. 느슨한 토큰 매칭을 허용하면 백운시장→백운계곡(포천) 같은 오매칭이 폭증한다.
- **목적**: CC가 다중 검색어로 후보표를 뽑고, 내(Claude)가 근거와 함께 y/n을 선판정, 애매한 것만 사용자가 육안 확인.
- **이유**: 채택 근거의 층위를 명시 — 띄어쓰기 차이(미리내성지)·공식명 차이(경원재)·동일 지번(망상해변)·행정개편 false negative(실미도: 2023 중구→영종구)는 채택. 다른 촬영지 사진 중복(구룡포 계단→역사관)·구역만 겹침(북촌 8경)은 거부.

## 3. 작성한 프롬프트
