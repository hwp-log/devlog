## 1. 한 줄 요약

0451~0455 읽기 화면 개편에 맞춰 작성·수정 화면을 정합 — 섹션 순서(본문→방문계획→방문장소), 눈썹 제거·h2 통일, PLAN 미리보기를 surface2 카드(h3+커버+소개+요약 한 줄)로 교체(트리맵 폐기), 요약 한 줄 파생식을 `lib/plan/summary-line.ts` 공용 함수로 추출, 편집 스팟 사이드 카드 면을 surface2·무테두리로 동조.

## 2. 왜 / 목적 / 이유

(초안 — 프롬프트 배경에서 추린 초안 수준)

- **왜**: 읽기 화면만 0451~0455에서 개편되어 작성·수정 화면과 어긋남 (같은 콘텐츠가 두 화면에서 다른 순서·다른 옷).
- **목적**: 두 화면의 섹션 순서·타이포·카드 문법을 한 벌로. 단 입력 필드(제목·태그·플랜 select)의 밑줄 스타일은 "여기 쓰는 곳" 신호로 유지.
- **이유(요약 줄 공용 함수)**: 읽기와 작성이 같은 문구("N일 · 스팟 N곳 · N인 · 총 약 N만원")를 만드는데 복제하면 한쪽만 고쳐 어긋남 — lib 추출로 단일 소스화 (사용자 확정).

## 4. 코드 작성 & 수정

### 1. 요약 한 줄 공용 함수 추출 (신규 `lib/plan/summary-line.ts`)

읽기 페이지의 인라인 파생식(0452)을 그대로 이동 — 읽기·작성 양쪽이 호출하는 단일 소스.

```typescript
export function buildPlanSummaryLine(input: {
  startDate: Date | null;
  endDate: Date | null;
  spotCount: number;
  headcount: number;
  showCost: boolean; // isPublic — false면 금액 조각만 생략
  band: PublicCostSummary['band'];
}): string {
  return [
    input.startDate && input.endDate
      ? `${Math.max(1, Math.ceil((input.endDate.getTime() - input.startDate.getTime()) / 86_400_000) + 1)}일`
      : null,
    input.spotCount > 0 ? `스팟 ${input.spotCount}곳` : null,
    `${input.headcount}인`,
    input.showCost && input.band
      ? `총 약 ${Math.round((input.band.lower + input.band.upper) / 2 / 10_000).toLocaleString()}만원`
      : null,
  ].filter(Boolean).join(' · ');
}
```
