# 0165 회고: 상세 패널 히어로·리스트 시안 정합

- **작성일**: 2026-08-10 (소급 작성 — 작업일 2026-07-12 오전)
- **소요 시간**: 약 1시간
- **관련 커밋**: `8e417ad` 상세 패널 히어로 - 사진 210px·제목 오버레이·작품 배지 좌상단 / `44bcd8e` 상세·리스트 시안 정합 - 배지 인라인, 검색 카피

## 1. 한 줄 요약

우측 패널을 히어로 문법(사진 210px + 스크림 + 제목 오버레이 + 배지 좌상단)으로, 좌측 리스트를 제목 옆 배지 인라인으로 바꾸고 검색 placeholder를 기능 대응 카피("드라마·영화 검색")로 교체 — 데이터 없이 가능한 시각 층만으로 시안 밀도에 접근했다.

## 2. 왜 / 목적 / 이유

- **왜(문제)**: 시안 우측 패널의 8할(평점·거리·복수 사진·작품 목록·스토리 집계)이 존재하지 않는 데이터라 "시안 90% 구현"이 불가능한 상태 — 목표를 "가진 데이터로 시안의 질감 최대치"로 재설정하고, 데이터 불필요한 시각 요소부터 입혔다.
- **목적**: 사진 한 장으로도 성립하는 히어로 구성(사진 위 제목·배지)과 리스트 한 줄 배치로, 패널·리스트가 시안의 그 밀도로 읽히는 상태.
- **이유(개별 판정)**: ① 스크림(linear-gradient rgba(13,13,20,...))은 밝은 사진 위 흰 제목의 가독 전제 조건 — 시안에 실재함을 CC가 실측으로 파냄. ② No Image 폴백에도 동일 스크림+제목 — 코드 경로를 하나로 유지. ③ 작품색 배지는 제외 — 작품 수가 늘면 색이 돌려막기 되는 문제를 실데이터에서 발견, 색 체계 자체를 별도 설계 안건으로 분리. ④ placeholder는 시안의 "드라마, 영화, 배우 이름 검색..."에서 배우를 뺐다 — 배우 검색 기능이 없어서, 없는 기능을 약속하는 카피 금지.

## 5. 결과 / 배운 점

- **결과**: 카드 총높이 불변(제목 블록 제거 −50px가 사진 증가 +50px 상쇄)이라 모바일 반응형 분기 불필요 — 계산으로 걱정 하나 소거. 긴 이름 프로브("국제금융공사 서울사무소") 통과.
- **min-w-0 함정**: flex 자식의 기본 min-width:auto가 truncate를 무력화한다 — CSS에서 가장 자주 밟는 함정을 검수 조건으로 선제 지정해 잡았다.
- **데이터 갭의 문서화가 곧 로드맵**: "시안대로 다 만들었다"보다 "시안 대비 데이터 갭을 식별하고 우선순위를 정했다"가 답 — 이때 정리한 8건(region·복수 사진·다대다·에피소드·평점·역참조·작품색 매핑·거리)이 이후 스키마 트랙(B1, StorySpot·SpotMovie)의 출발점이 됐다.
