# 0999 회고 작성 예시: 푸터에 사업자정보 표기 추가 (0614 기준)

> 이 파일은 회고 양식의 기준 예시다. 실제 0614 회고를 그대로 가져왔고,
> 사업자등록번호만 더미값으로 바꿨다. 새 회고를 쓸 때 이 구조·표현·분량을 따를 것.

**작성일**: 2026-08-26
**소요 시간**: 약 40분
**관련 커밋**: feat: 0614 푸터에 사업자정보 표기 추가 (`8a9b8e0`)

---

## 1. 한 줄 요약

전자상거래법 제10조 대응으로 푸터에 사업자 신원정보 6항목(상호·대표자·사업자등록번호·개인정보 보호책임자·이메일·호스팅 제공업체)을 인라인 블록 1개로 추가하고, 기존 아이콘 이메일 줄은 블록에 통합(제거).

---

## 2. 왜 / 목적 / 이유

왜: 결제를 붙이면서 전자상거래법 제10조 표시 의무가 따라왔다.
푸터에 사업자 신원정보가 없었다.

목적: 소비자가 사업자를 확인할 수 있게 하는 것. 다만 지금 단계에서
"전부 표시"가 아니라 "지금 표시할 수 있는 것만" 넣는 것을 목표로 했다.

이유 — 주소·전화번호를 왜 뺐나:
사업자등록이 자택으로 되어 있어 주소를 그대로 표시하면 동·호수까지
공개된다. 전화번호도 개인 휴대폰이다. 부분 표기(호수 생략)를 검토했으나
공정위 판단상 신원정보의 "일부 미표시"도 위반이라 불가.
게다가 시행규칙상 사업자정보 공개페이지를 초기화면에 연결해야 해서,
푸터에서 가려도 공정위 조회에서 전부 보인다.

결정: 주소·전화번호는 비상주 사무실 주소와 050 안심번호로 바꾼 뒤
통신판매업 신고 때 한 번에 처리한다. 지금 자택 주소로 신고하면
변경신고로 값은 고쳐도 검색 캐시·수집본은 회수되지 않는다.
현재 실매출이 없어 신고 시점이 아니므로, 나머지 6항목만 먼저 넣었다.

{/* 전자상거래법 제10조 사업자 신원정보. 이메일은 포워딩 설정 완료된 실주소(mailto 미연결).

    항목별 span + flex-wrap — 좁은 폭에서 항목 단위로만 줄바꿈. 구분자는 낭독 제외 */}

  <span>상호: 이음</span>
  <span aria-hidden>|</span>
  <span>대표자: 박현우</span>
  <span aria-hidden>|</span>
  <span>사업자등록번호: 000-00-00000</span>
  <span aria-hidden>|</span>
  <span>개인정보 보호책임자: 박현우</span>
  <span aria-hidden>|</span>
  <span>이메일: hello@dotrip.io</span>
  <span aria-hidden>|</span>
  <span>호스팅 서비스 제공업체: Vercel Inc.</span>

- 배치: 사업자정보 위 · © 최하단 — 한국 커머스 관행 준수 (CLAUDE.md §9)
- 스타일: `text-xs text-muted` — 기존 © 줄과 동일 토큰 조합, 임의 값 없음. 12px = 모바일 하한(§5) 준수
- 줄바꿈: 항목별 `<span>` + `flex-wrap`으로 항목 단위 줄바꿈만 허용, `break-keep`(§5). 구분자 `|`는 `aria-hidden`으로 스크린리더 낭독 제외

## 5. 결과 / 배운점

### 결과

- `npm run build` 통과
- 헤드리스 WebKit 실측(로컬 프로덕션 서버, `/story` 푸터):
  360px·390px·768px 전부 가로 스크롤 없음, 항목 중간 끊김 없음 (360/390 = 3줄, 768 = 2줄), 라이트·다크 모두 muted 12px 정상 렌더, 콘솔 에러 0건

### 배운점

법정 표시 의무는 "다 넣거나 안 넣거나"가 아니라 순서가 있었다.
푸터 한 줄 붙이는 작업인 줄 알았는데, 실제로는 사업장 주소 정책이
선행이었고 그건 통신판매업 신고 시점에 걸려 있었다.
코드 작업 앞에 제도 순서를 먼저 그려야 했다.

## 결정 (Decisions)

- 사업자정보 배치는 출처 표기 아래 · © 저작권 위 (한국 커머스 관행)
- 스팟파인더는 푸터 미노출 유지 — 법상 요구는 초기화면 표시이고
  다른 탭에서 도달 가능. 전체 화면 지도라는 레이아웃 예외도 유지
- 구분자 `|`는 시각 전용 — `aria-hidden`으로 낭독 제외, 항목별 span으로 항목 단위 줄바꿈만 허용
- 사업장 주소·전화번호·통신판매업 신고번호·약관/개인정보처리방침 링크는 이번 범위에서 제외 (각각 미확정 별건 / 0615)
