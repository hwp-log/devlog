# 0200 회고: 우측 패널 시안 보정 — 구분선·다녀온 이야기 카드화

작성일: 2026-07-14 / 소요: 약 40분 / 커밋: 7098769

## 1. 한 줄 요약
이야기 발췌를 시안의 둥근 인용 카드로 바꾸고 구분선을 넣었다 — 공유 컴포넌트의 두 배경 제약을 CC가 스스로 찾아 surface2를 골랐다.

## 2. 왜 / 목적 / 이유
- **왜**: 시안 대비 카드화·구분선·클릭 암시(›)가 없었다.
- **목적**: 카드(surface2, radius, 인용구 "…", 하단 작성자·♥·날짜, › hover). 스토리 사진은 유지("누가 다녀갔다"는 증거). 시안의 EP·년도 부제와 작품 포스터는 미채택(각각 일관성 없음·저작권).
- **이유(surface2)**: SpotDetailContent가 모바일(bg-card)과 데탑(bg-bg) 두 컨테이너에 공유 — card를 쓰면 모바일에서 카드가 배경에 묻힌다. 구분선은 조건부 블록 안(이야기 0건이면 dangling 선 방지).

## 3. 작성한 프롬프트
시안 실측값 반영 요구 + 발명 금지(EP·년도·포스터) + 클릭 이동은 별도 사이클 명시.

## 4. 작성·수정한 코드
```tsx
// SpotFinderMapNaver.tsx — 이야기 카드: bg-surface2/80 rounded, 인용구, 메타 줄, ChevronRight, hover
// 구분선: 조건부 border-t border-border pt-4
```

## 5. 결과 / 교훈
- 카드 사진 정책 확정: **StorySpot.photoUrl만, 폴백 없음** — 글 커버로 폴백하면 다중 스팟 스토리에서 다른 장소 사진이 뜬다. 카드의 사진은 "이 장소", 텍스트는 "그 글" — 두 층의 자리를 지킨다.
- 교훈: 공유 컴포넌트의 스타일 결정은 모든 소비 컨텍스트의 배경을 확인한 뒤에.
