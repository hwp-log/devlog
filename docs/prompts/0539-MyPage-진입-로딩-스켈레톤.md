---

## 1. 한 줄 요약

MyPage에 route-level 진입 로딩(`mypage/loading.tsx`) 신설 — 0491 방식 준용하되, MyPage는 뭐가 뜰지 아는 화면이라 틀·라벨·정적 카드(비밀번호 변경·계정 삭제)는 실물로 그리고 서버 데이터 자리(닉네임·이메일·아바타·지표 4값·최근 활동 행)만 shimmer.

---

## 2. 왜 / 목적 / 이유

(초안 — 초안)

- **왜**: MyPage에 진입 로딩이 없어 모바일 실기기에서 탭 후 반응이 없는 것처럼 보였다 — 호버가 없어 눌림 신호가 화면 전환뿐이라 공백이 길면 다시 누르게 된다.
- **목적**: 탭 즉시 실제 화면 골격이 떠서 "작동했다" 신호 + 전환 시 무시프트.
- **이유**: 기록 없음

## 4. 코드 작성 & 수정

### 조사 결과

- 선례: 작성·수정은 `StoryWriteSkeleton` 1벌 공유(0491 C-1), 상세는 단독 골격형(0490). 공통 — 틀은 실물·조건부 생략(C-2)·리터럴 준용+짝 주석(C-4). 0491 회고 파일은 없고 원칙은 주석이 정본.
- 데이터 분리: 서버 대기 = 닉네임·이메일·아바타·지표 4값·최근 활동 행(각 take 3)·닉네임 input 초기값. **비밀번호 변경·계정 삭제 카드는 데이터 0** — 폼 상태·펼침은 전부 클라이언트 초기값(빈/접힘)이라 통째 실물.

### mypage/loading.tsx 신설 (177줄)

```tsx
// 인사말 — "안녕하세요," 실텍스트 + 닉네임 자리만 인라인 shimmer
<h1 className="text-[26px] sm:text-[28px] font-bold ...">
  안녕하세요,{' '}
  <span className="inline-block h-[0.9em] w-24 rounded align-baseline skeleton-shimmer" />님
</h1>
// 지표 4칸 — 라벨 실텍스트, 값 자리만 shimmer (박스 h-[30px] = text-[20px] arbitrary lh 상속 1.5)
// 최근 활동 — 헤더·소제목 실물, 행 3개씩(take:3 상한 = 대표형)
// 오른쪽 카드 — page.tsx 로컬 const card 리터럴 복제(export 안 됨) + 짝 주석
// input 틀 h-[52px] = py-[13px]×2 + text-base lh 24 + border 2 (NicknameForm inputClass 짝)
```

버튼·input은 표시용 비인터랙티브 div(aria-hidden 루트). AvatarControls 조건부 버튼(사진 저장·제거)은 C-2대로 생략, 상시 노출 "파일 선택"만.

## 5. 결과 / 배운점

### 결과
- `npx tsc --noEmit` 통과. 360px: 모바일은 세로 스택 + 고정폭 요소 없음(바 최대 w-40) — 가로 스크롤 없음.
- 시프트 방지: 텍스트 자리 바는 실물 줄높이 박스(h-6·h-7·h-[30px]) 안에 배치 — 바 높이만 두면 줄높이 차로 어긋난다.

### 배운점
초안 — Tailwind 유틸 text-lg는 lh 내장(28px), arbitrary text-[20px]는 lh 상속(1.5)이라 스켈레톤 박스 높이 산식이 다르다
