# 0195 회고: 커버 보완 — searchKeyword2 백필·CDN 이전·로드검증 게이트

작성일: 2026-07-14 / 소요: 약 1.5시간 / 커밋: 02a6174

## 1. 한 줄 요약
"저장됨 ≠ 표시됨" — 저장된 커버 27개 중 3개가 404였다. 로드 검증 게이트를 신설하고, 죽어가는 CDN에서 살아있는 CDN으로 소스를 옮겨 29/45를 확보했다.

## 2. 왜 / 목적 / 이유
- **왜**: 화면에서 깨진 이미지 발견. 조사 결과 PhotoGallery의 `cms2/website/` 트리가 통째로 은퇴(재검색 20건 전부 404). 백필이 URL을 실검증 없이 저장했었다 — "60%"라고 보고했는데 실제는 53%.
- **목적**: ① 모든 백필에 로드 검증(GET 200 + image/*) ② 죽은 3곳 null 되돌림 ③ searchKeyword2(KorService2 이름 검색)로 살아있는 `cms/resource/` CDN에서 회복.
- **이유**: 경로 패턴 필터는 미봉책, HTTP 실검증이 정답. searchKeyword2 실측에서 별마로천문대가 죽은 소스에서 산 소스로 부활 — 두 API가 상호 보완적(좌표=유명 관광지, 이름=고유명사)임이 실증됐다. 소스 우선순위 확정: 좌표 → 이름 → PhotoGallery.

## 3. 작성한 프롬프트
로드 실패 조사(전수 HTTP 응답 코드·CDN 비교·원본 http 확인) → 처방 승인 + searchKeyword2 실측 추가 → 백필 승인(기존 PhotoGallery 커버 중 살아있는 것도 cms/resource로 이전 검토).
