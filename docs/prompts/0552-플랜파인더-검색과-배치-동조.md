## 2. 왜 / 목적 / 이유

(초안 — 초안)

- **왜**: 0551에서 MyPlan 배치를 정리했고, 같은 카드 목록인 플랜파인더가 다른 배치(헤더 행 우측 필터)·무검색이라 두 화면이 갈렸다.
- **작성자 포함 근거**: 공개 목록은 남의 코스를 찾는 화면 — "그 사람 코스 다시 찾기" 용례. 내 목록(0548)엔 작성자 개념이 없어 3필드였던 것.
- **필터 우→좌**: MyPlan(0551)과 같은 문법이라 어색 없음 판정. hairline 행 마감이 새로 생기는 것도 같은 배치의 구성 요소로 수용.
