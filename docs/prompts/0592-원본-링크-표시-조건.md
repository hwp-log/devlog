# 0592 회고: 원본 링크 표시 조건

**작성일**: 2026-08-17
**관련 커밋**: `d7e36e5`

---

## 1. 한 줄 요약

담은 플랜을 공개로 올리면 "원본 플랜 보기" 링크를 숨긴다 — 공개하는 순간 독립된 플랜으로 보되, DB의 `sourcePlanId`는 집계·배분용 연결로 그대로 둔다.

## 2. 왜 / 목적 / 이유

- 담아서 자기 일정으로 고친 뒤 공개했다면 **그건 그 사람의 플랜**이다. 출처 링크가 계속 붙어 있으면 어색하고, 남이 볼 때 **"베낀 것"으로 읽힐 여지**가 생긴다.
- 비공개 동안은 본인만 보므로 링크가 유효하다 — "어디서 담았더라"를 되짚는 용도다. 그래서 기존 `isOwner` 게이트와 짝이 맞는다.
- **데이터는 남긴다.** `sourcePlanId`는 나중에 담긴 횟수 집계·수익 배분에 쓸 연결이다. 표시를 끄는 것과 관계를 끊는 것은 다른 결정이다.

## 3. 작성한 프롬프트

```
- 현재: isOwner && sourcePlanId
- 변경: isOwner && sourcePlanId && !isPublic
- 근거를 주석에: 공개하는 순간 독립된 플랜으로 본다.
  DB의 sourcePlanId는 유지 — 집계·배분용 연결
[하지 말 것] ❌ sourcePlanId를 DB에서 지우거나 저장 시 끊기
```

**금지 항목이 판단의 절반**이었다. "표시를 끈다"와 "관계를 끊는다"를 갈라 놓은 것이 이 작업의 내용이다.

## 4. 코드 작성 & 수정

```tsx
        {isOwner && sourcePlanId && !isPublic && (
          <Link href={`/plan-finder/${sourcePlanId}`} …>원본 플랜 보기 →</Link>
        )}
```

조건 하나 추가가 전부다. 대신 **왜 데이터는 남기는지**를 주석에 박았다 — 나중에 "안 쓰는 필드"로 보여 지우고 싶어질 자리라, 표시가 없다는 사실이 관계가 없다는 뜻이 아님을 코드 옆에 남겨야 한다.

`sourcePlanId` 쓰기 경로를 전수 확인했다: 담기(`plan-finder/[id]/actions.ts:109`)에서 한 번 쓰고, 저장·수정 경로(`updatePlanWithItemsAction`)는 이 필드를 건드리지 않는다. **공개로 바꿔도 값은 그대로 남는다.** 이미 `mypage/actions.ts:170`이 이 필드로 조회하고 있어(탈퇴 처리) 연결이 살아 있음도 확인된다.

0591에서 쓴 주석 한 줄도 정정했다 — 조건이 바뀌어 `isOwner && sourcePlanId`라는 서술이 낡았고, 조건이 좁아지면서 **원본 링크가 없는 상태가 더 흔해졌다**는 사실을 DOM 순서 결정의 근거에 덧붙였다.

## 5. 결과 / 배운점

- `npx tsc --noEmit` 통과. `npx next build` 컴파일 성공. `npm test` 실패 목록 기존과 동일(6스위트/8테스트) — 회귀 없음.
- **실화면 확인 완료** — ① 담은 플랜(비공개)에서 링크가 보인다 ② 그 플랜을 공개로 토글하면 사라진다 ③ 사라진 뒤 `← 목록으로`가 좌측에 남는다.
- 배운점 초안 1: **표시를 끄는 것과 관계를 끊는 것은 다른 결정이다.** 화면에서 안 보이면 데이터도 필요 없어 보이지만, 이 연결은 집계·배분이라는 **아직 오지 않은 용도**를 위한 것이다. 지금 안 쓰는 필드를 남기는 판단은 근거를 코드에 적어 두지 않으면 다음 정리 사이클에서 지워진다.
- 배운점 초안 2: **공개 여부가 소유의 의미를 바꾼다.** 같은 플랜인데 비공개일 땐 "내가 담아 온 것"이고 공개하면 "내가 내놓은 것"이다. `isPublic`이 접근 제어(0557)를 넘어 **표시 의미의 축**으로도 쓰인 첫 사례다.
---

## 결정 (Decisions)

- **공개하면 그 사람의 플랜이다** — 원본 링크는 `isOwner && sourcePlanId && !isPublic`.
  공개하는 순간 독립된 플랜으로 본다.
- **`sourcePlanId`는 DB에 유지** — 담긴 횟수 집계·수익 배분용 연결. 표시를 끄는 것과 관계를 끊는 것은 별개.
- 저장·수정 경로는 이 필드를 건드리지 않는다(현행 유지, 확인 완료).

## 남은 것 (별건)

- **비용 주의 문구(0579·0590)와 판단이 갈린다.** 그 배너는 `sourcePlanId` 유무 하나로만 뜨고, 0580 주석에 "isOwner를 안 거는 이유는 담은 플랜을 나중에 **공개로 돌리면 남에게도 같은 사실이 성립**하기 때문"이라고 적혀 있다. 0592는 반대로 "공개하면 독립된 플랜"이라 본다. **공개된 담은 플랜에서 원본 링크는 사라지는데 "원본 작성 시점의 금액입니다" 배너는 남는다.** "다른 표시 조건 손대기" 금지라 이번엔 안 건드렸고, 두 판단 중 무엇이 정본인지는 미결이다.
