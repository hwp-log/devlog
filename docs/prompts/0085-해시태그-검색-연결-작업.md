# 0085 회고: 해시태그를 탐색 입구로 — 상세 태그 클릭 검색 연결

작성일: 2026-06-10
소요: 약 1시간
관련 커밋: 9bc5a37 (feat: 0085 스토리 상세페이지란의 해시태그 클릭 시 글 검색 연결)

## 1. 한 줄 요약
스토리 상세 페이지의 태그를 단순 텍스트(span)에서 링크(Link)로 바꿔, 클릭하면 같은 태그의 글 검색(`/story?q=`)으로 이동하게 연결했다. 커서와 hover 배경 변화로 클릭 가능함도 함께 알렸다.

## 2. 왜 / 목적 / 이유

**왜 (동기/문제)**
두 가지였다. ① 사용자가 상세 글을 읽다가 태그를 보면 "이 태그 달린 다른 글도 보고 싶다"는 탐색 욕구가 생긴다. ② `#`은 SNS에서 "누르면 같은 태그 글이 모인다"로 학습된 관습 기호라, 사용자는 `#`만 봐도 클릭을 기대한다. 그런데 태그가 클릭 안 되는 단순 텍스트(span)로 있으면 이 탐색 욕구와 클릭 기대가 둘 다 막히고, 기대가 어긋난다.

**목적 (도달할 상태 / 사용자 가치)**
태그를 탐색 입구로 만든다. 사용자가 한 글에서 관련 글로 끊김 없이 건너가게 하고, `#`이 주는 "클릭하면 관련 글이 모인다"는 기대를 실제 동작으로 충족한다.

**이유 (채택 근거 / 의사결정)**
0083에서 만든 태그 키워드 검색의 진입점을 상세 페이지 태그에 연결했다. 태그를 `Link`로 바꿔 `/story?q=태그명`으로 이동시키면, 별도 검색 화면 없이 기존 검색 흐름을 그대로 재사용한다. `#` 관습만 믿지 않고 `cursor-pointer`와 hover 배경 변화로 클릭 가능함을 시각적으로도 명시했다(0084의 행동 유도성과 같은 원리).

## 3. 작성한 프롬프트
(0085 당시 CC 프롬프트가 있으면 기입. 없이 직접 수정했으면 "프롬프트 없이 직접 수정"으로 기입.)

## 4. 코드 작성 & 수정

```tsx
// app/story/[id]/page.tsx — 태그를 span에서 Link로 변경

// 변경 전: 클릭 불가능한 단순 텍스트
<span
  key={tag.id}
  className="text-xs px-2 py-0.5 rounded-full bg-slate-100 text-slate-600"
>
  #{tag.name}
</span>

// 변경 후: 같은 태그 검색으로 이동하는 Link + hover/커서 피드백
<Link
  key={tag.id}
  href={`/story?q=${encodeURIComponent(tag.name)}`}
  className="text-xs px-2 py-0.5 rounded-full bg-slate-100 text-slate-600 cursor-pointer hover:bg-slate-200 transition-colors"
>
  #{tag.name}
</Link>
```

핵심 두 가지:
- `href={`/story?q=${encodeURIComponent(tag.name)}`}` — 태그명을 검색 쿼리(`q`)로 넘긴다. `encodeURIComponent`로 감싸는 이유: 한글이나 공백·특수문자가 든 태그가 URL 쿼리에서 깨지지 않고 안전하게 전달되게 한다.
- `cursor-pointer hover:bg-slate-200 transition-colors` — 클릭 가능함을 커서와 hover 배경 변화로 알린다.

## 5. 결과 / 배운점
- 결과: 상세 페이지 태그가 클릭 가능해졌고, 클릭 시 `/story?q=태그명`으로 이동해 같은 태그의 글이 검색된다. hover 시 배경색이 바뀌어 클릭 가능함이 드러난다.
- 배운점 1: 해시태그(`#`)는 SNS 관습상 클릭 가능으로 학습된 기호다. 단순 텍스트로 두면 사용자 기대를 배신한다 — 관습이 만든 기대를 실제 동작으로 채워야 한다.
- 배운점 2: 클릭 가능함을 `#` 관습에만 기대지 않고 커서·hover 변화로도 명시했다. 0084의 행동 유도성(시각 신호로 "누를 수 있음"을 알림)을 태그에 적용한 것이다.
- 배운점 3: URL 쿼리로 값을 넘길 때는 `encodeURIComponent`로 인코딩한다. 한글·공백·특수문자 태그가 URL에서 깨지는 것을 막는 안전장치다.
