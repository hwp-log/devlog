---

## 1. 한 줄 요약

0548의 검색바(헤더 아래 좌측)를 지표줄과 같은 행 우측("새 계획" 버튼 축)으로 이동 — [지표(좌) ··· 검색바(우)] 한 행, hairline은 행 전체 마감, 모바일 세로 스택(지표 → 검색바), 스켈레톤 동조.

---

## 2. 왜 / 목적 / 이유

- **왜**: 위치 조정은 사용자 지정. 검색바가 우측 정렬이라 "새 계획" 버튼 바로 아래 축에 놓이는 형태 — 버튼과 한 덩이로 안 붙게 mt-2(헤더 mb-6 합산 32px) 여백.
- **판단 3건**: 세로 정렬 center(baseline은 40px input 박스가 쏠려 보임) / 모바일 순서 지표 → 검색바(데스크톱 좌→우 독서 순서 유지, DOM 동일) / hairline 행 전체 걸침이 자연(행 단위 마감 — 지표 밑에서만 끊기면 우측이 떠 보임).
