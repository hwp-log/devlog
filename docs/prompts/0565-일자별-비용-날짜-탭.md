## 1. 한 줄 요약

읽기 화면 "여행 일자별 비용"의 [날짜 칩 + 소계] 세로 반복(0563)을 날짜 탭 한 줄로 바꾸고, 위 "여행 일정" 섹션의 인라인 날짜 탭을 공용 `DayTabs`로 추출해 두 섹션이 같은 컴포넌트를 쓰게 했다.

## 2. 왜 / 목적 / 이유

### 세로 반복 → 탭
- **왜**: 날짜가 여럿이면 [날짜 칩 + 소계 + 장소들]이 날짜 수만큼 세로로 쌓여, 한 프레임에 들어오는 정보량이 날짜 수에 비례했다.
- **목적**: 정보량을 하루치로 고정.
- **이유**(현우): 한 프레임 정보량이 정해져 있으면 인식 부담이 일정하다. 그리고 탭이 보이므로 **다른 날이 있다는 사실 자체**는 잃지 않는다 — 접기와 달리 숨김의 대가가 없다.

### 복제가 아니라 추출
- **왜**: 일정 섹션의 날짜 탭이 컴포넌트가 아니라 `PlanFinderDetail`에 인라인이었다(0515).
- **목적**: 두 탭이 한 벌.
- **이유**(현우): 같은 플랜의 **같은 날짜**를 표시하는 두 탭이라 형태가 갈리면 안 된다. 두 벌이면 다음에 한쪽만 고치게 된다. — 0524 `cat-*` 토큰, 0563 표시 언어 통일과 같은 판단.

### 탭 = 비용 있는 날만
- **왜**: 일정은 있는데 비용을 안 넣은 날이 있을 수 있다.
- **목적**: 헛걸음 제거.
- **이유**(현우): 눌러도 빈 화면인 탭은 헛걸음이고, 이 섹션은 "얼마 썼나"를 보는 자리라 지출 없는 날은 정보가 아니다. 일정 탭과 개수가 달라지는 건 오히려 정확한 표시.
  코드 쪽 근거도 같다 — `dayGroups`는 존재하는 `PlanCost` 행에서만 파생되고, 0499가 이미 "비용 없는 날은 그룹 자체가 안 생김"으로 답을 냈다. 여기서 뒤집으면 한 화면에 두 원칙이 생긴다.

### 접기 유지
- **왜**: 그룹이 기본 접힘인데 그 안에 탭이 들어가 조작이 두 겹이 된다.
- **이유**(현우): 고정 비용·항공권 그룹이 접기라 일자별만 안 접히면 세 그룹의 형태가 어긋난다. 탭이 세로를 줄여도 그룹 자체는 여전히 접히는 단위다.
  (부수 효과: 지금까지 "펼치기"는 날짜 수만큼 세로가 늘어나는 비싼 조작이었는데, 탭 도입 후 펼친 높이가 하루치로 유계가 됐다.)

### 기본 선택 = 비용 있는 첫 날
- **이유**: 일정 탭의 `useState(1)` 첫날 고정을 복제하면 1일차에 비용이 없을 때 첫 화면이 빈다. 탭 목록이 곧 비용 있는 날이므로 `dayGroups[0].day`가 자연스러운 첫 탭.

### 탭이 1개여도 생략하지 않음
- **이유**(현우): 그날이 언제인지 알려주는 정보이고, 플랜마다 형태가 달라지면 안 된다.
  (그 줄은 탭이면서 동시에 구 날짜 칩 줄의 머리글 역할 — 어느 날 · 소계 — 을 승계한다.)

### 1. `DayTabs` 추출 (`ea4e38b`) — 렌더 무변

export function DayTabs({ days, selected, onSelect, label, right }: {
  days: number[]; selected: number; onSelect: (day: number) => void;
  label: (day: number) => string;
  right?: ReactNode;   // 0565 비용 소계 전용(일정은 미사용) — 스크롤 밖 형제라 같이 밀리지 않는다

        <div className="flex gap-1.5 sm:gap-2 overflow-x-auto pb-1 max-sm:pr-6">

              className={`px-4 py-1.5 rounded-full text-sm whitespace-nowrap transition-colors shrink-0 ${

              {label(d)}
            </button>))}

호출부(일정) — 클래스 문자열은 그대로 이관, 여백만 호출부에 남김:

### 2. 비용 섹션 탭화 (`6ce77d4`)

```tsx
// 0565: 선택 날짜. null = "아직 안 고름" → 파생으로 dayGroups[0].day를 쓴다.
//   초깃값에 실제 날짜를 박지 않는 이유: dayGroups는 props에서 오므로 같은 사실이
//   상태와 props 두 곳에 생긴다(단일 소스 + 파생).
const [pickedDay, setPickedDay] = useState<number | null>(null);

const costDays = dayGroups.map((g) => g.day);
const selectedCostDay =
  pickedDay != null && costDays.includes(pickedDay) ? pickedDay : costDays[0];
const selectedGroup = dayGroups.find((g) => g.day === selectedCostDay);
```

```tsx
{dayOpen && selectedGroup && (
  <div className="flex flex-col">
    <div className="pb-2 border-b border-fg/15">        {/* 밑선은 0563 그대로 승계 */}

        label={dayDateLabel}
        right={<span className="shrink-0 pb-1 text-sm font-semibold text-cost-amount tabular-nums">
          {formatAmount(selectedGroup.total, currency)}
        </span>} />
    </div>
    {selectedGroup.places.map(/* 0563 조판 그대로 — 무변 */)}
  </div>
)}
```

- 구 `dayGroups.map(...)` 세로 반복과 날짜 블록 간 `mt-[26px]` 소멸(블록이 하나뿐).
- 소계 `pb-1`: 탭 스크롤 컨테이너의 `pb-1`이 탭 중심을 2px 올려두므로, 같은 값을 소계에 주면 시각 중심이 맞는다.
- **장소·카테고리 JSX는 한 글자도 안 건드렸다**(0563 확정분).

## 5. 결과 / 배운점

### 결과
- `npx tsc --noEmit` 통과.
- `npm test` — 6 스위트 / 8 테스트 실패. 기존 실패 목록(auth 5 + SpotPopup)과 **완전 일치** → 회귀 없음.
- 실화면 판정: — 실 클래스 값으로 만든 대조 시안(라이트·다크 × 360·768, 탭 3개·7개·1개)을 별도 전달. 탭 1개일 때 채운 pill 과강조 여부가 남은 판정 항목.

### 배운점
- **탭은 접기와 다른 종류의 숨김이다** — 접기는 "있다는 사실"까지 접지만, 탭은 목록을 남긴 채 내용만 바꾼다. 그래서 두 장치가 겹쳐도 조작이 중복되지 않고 층위가 갈린다(섹션을 볼지 / 그 안 어느 날).
- **인라인 조각의 추출 시점 = 두 번째 호출부가 생길 때, 그것도 "같은 대상"을 그릴 때** — 0515 시점엔 탭이 하나였으니 인라인이 맞았다. 추출을 정당화한 건 재사용 횟수가 아니라 **두 탭이 같은 플랜의 같은 날짜를 표시한다**는 사실이다. 다른 대상이면 형태가 갈려도 문제가 아니다.
