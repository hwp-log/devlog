# 0187 회고: 우측 패널 메타 카드 — 아이콘 그리드

작성일: 2026-07-13 / 소요: 약 1시간 / 커밋: 79ecd9e

## 1. 한 줄 요약
메타 줄을 시안 실측 스펙의 2열 아이콘 카드 그리드로 교체했다 — 시안을 따르되 원칙과 충돌하면 원칙이 이긴다.

## 2. 왜 / 목적 / 이유
- **왜**: 시안은 30×30 아이콘 박스 + 2열 그리드인데 구현은 텍스트 줄이었다. 1차 구현은 세로 스택으로 축이 틀려 "이 장소에서 촬 영" 같은 줄바꿈 깨짐이 났다.
- **목적**: 시안 실측값(grid 1fr 1fr, gap 11px, 카드 flex gap 9px, 아이콘 30×30 radius 9, 주 12.5px w400) 그대로 재현. 3칸(교통·작품·스토리), 별점 자리는 B2까지 빈칸.
- **이유**: 의도적 편차 3건 승인 — ① 부제 11px→12px(가독성 하한 §5 우선) ② 교통 부제 "도보 가능" 생략(주 문구에 수단 포함, 중복) ③ 가로 패딩 16px(형제 정렬이 시안 밴드 재현보다 우선). 아이콘은 lucide→**이모지 회귀**(사용자 결정, 시안 원본 존중. OS별 렌더 편차는 표지로).

## 3. 작성한 프롬프트
시안 HTML을 직접 실측해 스펙을 프롬에 박음(grid·padding·radius·font 수치 명기). 이모지 회귀 지시 시 lucide import 정리 포함.

## 4. 작성·수정한 코드

1파일 30+/4-. 0186이 만든 메타 2줄(`flex flex-col gap-1`)을 아이콘 카드 2열 그리드로 교체.

```tsx
// components/SpotFinderMapNaver.tsx
// 메타 — 아이콘 카드 2열 그리드 (시안 실측). 교통/작품/스토리 3칸 → 2열이라 4번째 셀은 빈 칸
// (B2 별점 자리 — 플레이스홀더 금지). 새 색 토큰 없음.
// 부제 11px는 CLAUDE.md §5 하한(12px)으로 클램프
<div className="grid grid-cols-2 gap-[11px] border-b border-border pb-[15px]">
  {spot.nearestStation && spot.transitMinutes != null && (
    <div className="flex items-start gap-[9px]">
      <div className="w-[30px] h-[30px] rounded-[9px] bg-surface2 border border-border
                      flex items-center justify-center shrink-0">
        <span className="text-[12.5px] leading-none">🚉</span>
      </div>
      {/* 주 문구 = 좌측 리스트 메타줄과 동일(formatTransit 단일 소스).
          수단(도보/차로)이 이미 담겨 부제 생략 — §8② 중복 회피 */}
      <span className="block text-[12.5px] font-normal text-fg break-keep">
        {formatTransit(spot.nearestStation, spot.transitMinutes)}
      </span>
    </div>
  )}
  {/* 🎬 작품 N편 / 이 장소에서 촬영 · ✍️ 스토리 N편 / 다녀온 기록 — 같은 카드 골격에 주+부제 2단 */}
</div>
```

교통 카드만 **조건부**(`nearestStation && transitMinutes != null`)이고 부제가 없다 — 나머지 둘은
주 문구 + 부제 2단이다. 이 비대칭이 의도인 이유가 위 주석에 남아 있다(수단이 주 문구에 이미 있음).

구 조판(0186)에서 바뀐 점: `border-t … pt-4` → `border-b … pb-[15px]`, 줄 나열 → 2열 그리드.

## 5. 결과 / 교훈
- 1파일 30+/4-.
- 교훈: **시안은 참조지 법이 아니다.** 프로젝트 규칙(가독성 하한·중복 금지·형제 정렬)과 충돌하면 규칙이 이기고, 그 근거를 편차 보고로 남긴다.
