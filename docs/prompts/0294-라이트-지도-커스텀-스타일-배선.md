# 0294 회고: 라이트 지도 커스텀 스타일 배선 — 테마별 customStyleId

**작성일**: 2026-07-20
**관련 커밋**: `6e8473c` feat: 0294 라이트 지도 커스텀 스타일 배선 - 원거리 이동 검정 캔버스 완화, 다크 무변

---

## 1. 한 줄 요약

지도 생성 옵션의 customStyleId를 테마별로 배선 — 다크 = 기존 `STYLE_ID`(무변), 라이트 = 신설 `NEXT_PUBLIC_NAVER_MAP_STYLE_ID_LIGHT`(env 미설정 시 옵션 미전달로 SDK 기본 폴백). 테마 전환 적용은 기존 지도 재생성 배선(0284)이 그대로 담당.

---

## 2. 왜 / 목적 / 이유

- **왜**: 라이트 지도에서 원거리 카메라 이동 시 미로드 타일 영역이 검정 캔버스로 노출(직전 조사 — 제어 가능한 배경 2겹은 이미 밝음, GL 캔버스 내부라 SDK 옵션으로 직접 제어 불가). [사용자 확인 필요]
- **목적**: 라이트 전용 커스텀 스타일(밝은 배경 레이어)로 검정 노출 완화 + 라이트/다크 각각의 타일 스타일 운용.
- **이유**: 삽입 지점이 기존 다크 ternary 1곳(직전 조사에서 특정)이라 배선 비용 최소. STYLE_VERSION은 미사용 실측 확정(사용자)이라 관련 코드 불추가. CLIENT_ID는 스타일 무관 공용 인증 키라 무변.

---

## 3. 작성한 프롬프트

```
[배경]
라이트 지도 커스텀 스타일 신설. env에 NEXT_PUBLIC_NAVER_MAP_STYLE_ID_LIGHT 추가 완료(사용자).
STYLE_VERSION은 미사용 실측 확정. 기존 STYLE_ID는 다크용 유지.
목적 = 라이트 원거리 이동 시 검정 캔버스 완화.

[작업]
1. 라이트 분기 배선 — 라이트일 때 customStyleId = STYLE_ID_LIGHT, 다크 분기 그대로
2. undefined 폴백 — 라이트 env 없으면 SDK 기본, 크래시 없게

[하지 말 것]
다크 분기 변경 ❌ / CLIENT_ID ❌ / STYLE_VERSION 코드 추가 ❌ /
테마 전환 로직 변경 ❌ / 실제 ID 하드코딩 ❌ / 커밋 ❌
```

## 4. 코드 작성 & 수정

### `components/SpotFinderMapNaver.tsx` — 지도 생성 옵션 (분기 1곳)

```ts
...(supportsGl
  ? {
    gl: true,
    ...(resolvedTheme === 'dark'
      ? { customStyleId: process.env.NEXT_PUBLIC_NAVER_MAP_STYLE_ID }          // 다크 — 무변
      : (process.env.NEXT_PUBLIC_NAVER_MAP_STYLE_ID_LIGHT
        ? { customStyleId: process.env.NEXT_PUBLIC_NAVER_MAP_STYLE_ID_LIGHT }  // 라이트 — 신설
        : {})),                                                                 // env 미설정 → SDK 기본 폴백
  }
  : {}),
```

## 5. 결과 / 배운점

### 결과
- 빌드 성공, `npm test` 기존 실패(6스위트/8테스트) 외 증가 없음.
- 번들 실측: 다크·라이트 스타일 ID가 각각 인라인됨(`customStyleId:"85b5…"` / `"2779…"` — .env.local 값과 일치). NEXT_PUBLIC은 빌드 타임 인라인이라 env 미설정 빌드에선 폴백 분기가 `{}`로 상수 접힘 — 크래시 경로 없음.
- 테마 전환 로직 무변 — 재생성 배선(0284)이 스타일 교체를 자동 담당. WebGL 미지원 래스터 폴백도 무변(양 테마 커스텀 미적용).
- **배포 주의(사용자)**: NEXT_PUBLIC이라 Vercel 환경 변수에도 `NEXT_PUBLIC_NAVER_MAP_STYLE_ID_LIGHT` 추가 + 재배포 필요. Style Editor에서 라이트 스타일 배포 상태 확인.
- 브라우저 수동 확인 잔여(사용자): 라이트 지도 타일이 신규 스타일로 뜨는지, 원거리 이동 시 검정 노출 완화 체감(캔버스 내부 색 직접 제어는 불가 — 스타일 배경 레이어 밝기에 따른 완화), 다크 무변.

## 결정 (Decisions)

- **지도 타일 스타일 = 테마별 customStyleId 페어**(env 2개) — 0284의 "라이트 = SDK 기본" 결정을 대체. 라이트 env 미설정이면 SDK 기본 폴백이 그 결정의 안전망으로 잔존.
- STYLE_VERSION env는 미사용 확정(코드 소비 0곳·제거해도 정상 실측) — env 정리 시 삭제 후보.
