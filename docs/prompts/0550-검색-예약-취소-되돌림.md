# 0550 검색 예약 취소 되돌림

**작성일**: 2026-08-07
**소요 시간**: 기록 없음
**관련 커밋**: fix - 0550 0549 예약 취소 되돌림 - 말미 음절은 커밋 전 compositionend가 없다 (61cd4c0)

---

## 1. 한 줄 요약

0549(compositionstart에서 대기 타이머 취소) 후 검색이 커밋(조작)까지 멈추는 회귀 — 원인은 **한글 마지막 음절은 커밋 전까지 compositionend가 발생하지 않아** 취소가 말미 구간의 유일한 예약을 죽인 것. A(만료 재예약)·B(디바운스 단축)도 같은 이유로 무효라 C(되돌림) 채택.

---

## 2. 왜 / 목적 / 이유

- **관찰(사용자 확정)**: "경주" 입력 후 손을 떼면 아무 조작 없이는 결과가 안 뜨고, 조작 후에야 떴다.
- **원인**: compositionend는 음절 경계에서만 오고 마지막 음절은 커밋까지 조합 유지. 0549 이전의 체감 반응성은 "직전 확정 음절(경)의 상위집합 검색"이 담당하고 있었는데, 0549가 그 예약을 취소해버림.
- **A·B 기각**: 둘 다 발화 조건이 compositionend인데 마지막 음절엔 그 이벤트 자체가 없음.
- **C 채택**: 중간 음절 검색은 부분일치의 상위집합 프리뷰("경" ⊇ "경주")로 수용 — 0548에서 본 "경북·경기 노출"은 이 구조의 대가.

---

## 3. 작성한 프롬프트

```
[배경] 0549 후 검색 반응이 느려짐("검색은 되는데 바로 안 됨").
[먼저 확인] ① "경주" 입력 시 이벤트 순서·마지막 compositionend 시점·취소 횟수 ② 지연 실측 비교
[후보] A 만료 시 재예약 / B 취소 유지 + 디바운스 단축(120ms) / C 되돌림(중간 노출 감수)
[하지 말 것] ❌ Enter 전용 ❌ 검색 대상·정규화 변경 ❌ 푸시
[검수 모드] ①② 선보고 → plan / 입력 유형별 지연 표 / npx tsc --noEmit
```

## 5. 결과 / 배운점

### 결과
- `npx tsc --noEmit` 통과. MyStory 포함 0086~0548의 검증된 동작으로 원상 복구.
- 후속 판정 후보 D: scheduleSearch가 만료 시점 최신 입력값을 읽으면 정지 시점 표시 텍스트("경주")로 정확 검색 가능 — 단 자모 꼬리("경ㅈ") 정규화 판정 선행 필요.

### 배운점
초안 — IME의 마지막 음절은 "확정처럼 보이지만 미커밋" — compositionend 기반 전략은 말미 구간에서 성립하지 않고, 이 사실은 코드가 아니라 실사용 관찰로만 확정됐다
