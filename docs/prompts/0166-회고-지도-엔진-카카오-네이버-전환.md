# 0166 회고: 지도 엔진 카카오 → 네이버 전환 (다크 커스텀 타일)

- **작성일**: 2026-08-10 (소급 작성 — 작업일 2026-07-12 오후)
- **소요 시간**: 약 3.5시간 (엔진 검토·NCP 구축 포함)
- **관련 커밋**: `619e3e9` 지도 엔진 카카오 → 네이버 전환 (다크 커스텀 타일) / `7967923` 3열 구분선 정합 - 지도 열 우측 경계

## 1. 한 줄 요약

"다크 UI 위의 원색 카카오 타일" 부조화를 풀기 위해 구글·Mapbox·네이버를 비교 검토한 끝에, 국내 상세도와 Style Editor 커스텀을 동시에 주는 네이버로 전환 — dotrip-dark 커스텀 스타일을 제작·발행하고 병렬 파일 + wrapper 1줄 스위치로 롤백 경로를 확보한 채 마이그레이션했다.

## 2. 왜 / 목적 / 이유

- **왜(문제)**: 카카오는 타일 스타일 커스텀을 열어주지 않아, 다크 차콜 UI 옆에 노란 도로·연두 산의 원색 타일이 그대로 붙었다. UI와 지도가 서로 싸우는 상태 — 시안의 "어둠 위 발광"이 성립 불가.
- **목적**: 국내 상세도를 유지하면서(촬영지 서비스의 본질) 타일을 브랜드 다크 톤으로 물들인 지도.
- **이유(엔진 결정)**: 요구축 5개(국내 상세도·다크 커스텀·경계 깨짐 처리·검색·비용)로 비교 —
  - **구글**: 한국 지도는 티맵 제휴 데이터라 상세도가 밀리고, 다크는 colorScheme와 MapId 커스텀의 catch-22 보고가 있어 불확실. 결제 관문(₩16,000 선불)에서 "불확실한 것에 돈·시간을 쓰지 않는다"로 중단. 타깃에 외국인이 있다는 논거는 유효하나 "지도에 해외를 그릴 필요"(없음)와 "익숙한 지도"(취향)를 구분해 v1.0 범위 밖 판정
  - **Mapbox**: 다크 스타일의 왕이고 시각적으론 최적이었으나, 과거에 검색 품질로 떠난 이력 + 세 번째 이사 비용으로 기각
  - **네이버**: Map Style Editor가 라이트/다크 커스텀 지원 + 국내 상세도 유지 + 월 600만 회 무료 + 예치금 없음 — 유일하게 트레이드오프가 없는 카드
- **이유(마이그레이션 전략)**: 영구 어댑터 레이어는 기각(최종 유지 엔진 1개에 과설계) — 대신 병렬 파일(SpotFinderMapNaver.tsx 신설, 카카오 파일 동결) + wrapper 1줄 스위치로 전환기 롤백만 확보.

## 5. 결과 / 배운 점

- **결과**: 다크 타일 위 애저 마커가 처음으로 성립. 0164에서 "안 보였던" 3열 구분선이 색 문제가 아니라 밝은 타일 옆 대비 부재였음도 규명(다크 타일 전환으로 자연 해소 + 지도 열 border 1줄).
- **스타일링 시행착오의 결론**: 남색 판에 초록(녹지)·갈색(관심영역)을 남기면 무조건 탁해진다 — "채도는 거의 0, 명도로만 위계, 강조는 물과 마커에만"이 다크 지도의 원리. 여러 번 "말라비틀어진 색"을 만든 끝에 Mapbox Dark를 레퍼런스로 확정.
- **벤더 코드도 실측 대상**: 네이버 공식 배포 유틸에 오타 버그(_mapRelation)가 있었다. "공식이니 맞겠지"가 아니라 실기동 계측이 잡았고, 패치는 원본과의 차이를 주석으로 남기는 관례를 세웠다.
- **결정 과정의 교훈**: 후보(구글)에 마음이 먼저 기울고 요구사항을 나중에 적어서 반나절을 돌았다 — 정상 순서는 문제 정의 → 요구축 → 후보 평가 → 실물 확증. "추측으로 아키텍처 결정하지 않기"가 지도에도 그대로 적용된 사례. 부수 수확: 경계 깨짐이 엔진 문제가 아니라 minZoom/maxBounds 설정 문제였음을 검토 중에 발견.
