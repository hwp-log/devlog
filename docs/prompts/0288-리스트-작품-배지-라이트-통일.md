## 1. 한 줄 요약

좌측 리스트 스팟 행의 작품 배지("미생 +1" 등, `renderSpotText`)를 데탑 라이트에서 검색바·칩(0287)과 톤 통일 — ① 테두리 제거 ② 배경을 `surface2` → 칩과 동일한 `card` 토큰으로. 다크·모바일 시트는 전량 현행 보존.

---

## 2. 왜 / 목적 / 이유

- **왜**: 리스트 항목의 작품 배지(미생 +1 등)가 테두리 + 다른 회색 토큰(surface2)이라, 0287에서 통일한 검색바·칩(card)과 톤이 어긋났다.
- **목적**: 배지를 라이트에서 무테두리 + 필터 칩과 같은 배경(card)으로 통일.
- **이유**: 배경까지 제거하면 라벨이 흰 리스트에 묻히므로 배경은 남기고, 검색바·칩과 같은 토큰으로 맞춰 좌측 열 회색 pill 언어를 배지까지 확장. 다크는 lg 스코프 페어로 보존.

## 5. 결과 / 배운점

### 결과
- 빌드 성공, `npm test` 기존 실패(6스위트/8테스트) 외 증가 없음 (두 소작업 각각 확인).
- 캐스케이드 순서 실측: 폭 `.lg:border-0`(773) < `.lg:dark:border`(822) / 배경 `.lg:bg-card`(777) < `.lg:dark:bg-surface2`(825) — 다크 복원이 항상 뒤.
- caveat 1건(수용·주석 명기): 데탑 라이트에서 행 hover 배경이 card라 hover 순간 배지 형태가 행 배경과 동화 — 일시 상태·텍스트(fg2) 유지라 칩 색 통일을 우선. 체감 문제 시 hover 행 배경을 popover로 조정하는 선택지.
- 브라우저 수동 확인 잔여(사용자): 데탑 라이트에서 흰 행 위 무테두리 card 배지 가시성, hover 동화 체감.

### 배운점
- 좌측 열 회색 pill 언어라는 룰이 확립됨 — 검색바·필터 칩·배지가 전부 card 토큰, 무테두리, 라이트만(lg 스코프 페어로 다크 보존). 흩어진 색 판단이 재사용 가능한 규칙으로 굳은 사례.
- hover 시 행 배경(card)과 배지(card)가 잠깐 동화될 수 있음 — 일시 상태라 수용, 거슬리면 hover 배경 조정.

## 결정 (Decisions)

- **좌측 열 회색 pill 언어 = 무테두리 + card 배경으로 단일화** (검색바·칩·배지 완결). surface2는 다크·모바일 배지와 상세 패널 카드류에 유지.
- **공용 토큰의 라이트 한정 변경 = `lg:` 변경 + `lg:dark:` 복원 페어** 관례 확정 (0287 폭 → 0288 폭·배경으로 3례).
- **공유 렌더러의 문맥 차이는 브레이크포인트 스코프로 분리** — 렌더러는 쪼개지 않는다 (0287 칩 판단 재적용).
