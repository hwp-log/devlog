# SpotFinder 모바일 개편 백로그

작성일: 2026-07-15 · 갱신일: 2026-07-17
대상: 모바일 SpotFinder (lg 미만). 데스크탑(lg 이상)은 이번 범위 밖 — 단 마커 호버는 데탑 포함.
원칙: 큰 틀은 업계 표준 준수 + 근거 명시. 드래그·스냅 바텀시트 미채택(제스처 충돌 회피, 비드래그 탭 기반).

---

## A. 완료 (커밋·푸시됨)

### 초기 (0228~0230)
- **0228** 하단 탭바 밀착 바 → 인셋 floating pill 전환 + 스팟 카드 바닥밀착 시트화 (`08e09a7`)
- **0229** 스팟 카드 표시 중 안내 배너 숨김 (카드 없을 때·데스크탑은 표시 유지, `hidden lg:flex`) (`514a4b2`)
- **0230** 스팟 카드 텍스트 재배치 (제목 전체 폭·안 잘림, 배지 아래 줄, 스토리 편수 줄 제거) (`2e49b61`)

### 대개편 (0228~0272, 나흘 반)
- **탭바 pill·카드 시트·테두리** (0228~0234) — floating pill 전환, 카드 시트화, pill 테두리·음영 강화
- **S1~S4 대개편** (0232~0240) — 상단 검색·칩 제거, 미선택 시트 추가, 선택 해제 동선, 작품 칩 필터·스팟 목록 시트 이식, 배너 시트 이관·축척 바 제거, 출처 표기 상세뷰 이동
- **가로 방어 오버레이** (0241) — 가로 모드 안내 오버레이
- **시트 다듬기** (0242~0248) — 목록 상시 노출+하이라이트, 탭 토글, 3단→2단(full 제거), 지도 확대 룰 데스크탑과 통일
- **상세 배지·✕ 가시성** (0249)
- **iOS Safari 목록 붕괴 수술** (0253~0256) — 명시 높이·하한 완화·고정부 압축으로 실기기 Safari 목록 높이 확보
- **걸침 전환·pill 뒤 연장·상하 경계** (0257~0259) — 시트 목록 1행+걸침으로 지도 확대, 탭바 뒤까지 연장, 상하 경계 다듬기
- **상세 스크롤 복구** (0260)
- **마커→목록 정렬 재구현** (0261) — 선택 스팟 목록 자동 정렬
- **행 동작 재배치** (0262)
- **상세 열기 슬라이드 업** (0263)
- **마커 라벨 확정** (0267·0269, 0268 결번; 앰버 검토 기각 이력) — 회색 유지 + 테두리 0.5 + 미세 입체
- **데탑 호버 마커 강조** (0270)
- **목록 선택 회색 틴트** (0271)
- **호버 강조 명도 상승** (0272)

> 자리표시자 메모: 커밋 `1a2a3b8` "025X"는 실질 **0252** (번호 미치환). 0250·0264~0266은 revert됨(아래 킵 참조).

---

## B. 호버 인터랙션 결정 기록

- **최종 채택**: 강조 + 명도 상승만 (0270·0272).
- **되돌린 것**: pan·선택 동기까지 전부 구현해 실측 비교 후 되돌림.
- **근거**:
  - 의도 없는 화면 변화(pan)는 어지러움 유발 → 기각.
  - 앰버 색 차용은 선택(파랑)과 인지 경쟁 → Material 상태 차등 원칙에 따라 무채 명도 반응 채택.
  - 화면 밖 스팟 접근은 호버가 아니라 클릭의 영역.

## E. 이번 세션 배운점 (다음 세션 인수인계 맨 앞에)

- 형태 논의는 반드시 시안 원문 확인부터. 이전 세션의 "시안 분리 구조" 결론은 오독이었음(실제: 카드 바닥밀착 시트 + 탭바 pill이 그 위에 뜸). 전제로 물려받지 말 것.
- 커밋 전 `git diff`로 실제 변경 확증. 의도 밖 변경(예: 배너 잔재)이 섞였는지 확인.
- 괄호 포함 경로(`app/(protected)/...`)는 zsh에서 따옴표로 감싸기.
- 인터랙션은 실측 후 되돌릴 수 있음 — 구현 비용을 아끼려 판단을 앞당기지 말 것 (호버 pan·동기 구현 후 기각 사례).
- iOS Safari 시트 높이는 데스크탑/시뮬레이터로 검증 불가 — 실기기 실측 필수.
