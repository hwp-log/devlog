## ① 컨셉

Dotrip은 K-콘텐츠(영화·드라마)의 "한 장면"을 여행하는 서비스다. 화면 속 한 장면은 곧 실재하는 촬영지이고, 사용자는 그 장소를 지도에서 찾아(SpotFinder) 여행 계획으로 엮고(MyPlan) 실제로 다녀온 감정과 기억을 기록해(Story) 다른 여행자와 공유한다(PlanFinder). 즉 Dotrip의 한 사이클은 **발견 → 계획 → 경험 → 기록 → 공유**이며, 모든 화면은 이 사이클의 한 단계를 담당한다.

**경험 단계는 오프라인(실제 여행)에서 일어난다.** Dotrip이 대신 느껴주는 것이 아니다. Dotrip은 그 경험을 준비하고(발견·계획), 잘 보관하도록 돕는(기록·공유) 도구다.

- 브랜드 시그니처: **점(dot)** — 로고의 점, 점선 루트, 스틸컷 썸네일 마커, 점 타임라인. "화면 속 한 장면이, 지도 위의 한 점이 된다."

### ③-1. SpotFinder (`/spot-finder`) — S급, 완성 명세

#### 데이터
- 서버: `fetchSpotFinderSpots()` → Spot[] (좌표, 이름, 사진, 리뷰, movie 관계)
- 파생: 작품별 스팟 수(칩 라벨), 필터된 스팟 목록

#### 상태 — 원천 2개, 나머지는 전부 파생
| 원천 상태 | 변경 트리거 | 변경 시 효과 |
|---|---|---|
| `selectedMovieId: string \| null` | 작품칩 탭 | selectedSpotId → null 리셋, 카메라 **jump**(필터 스팟 전체 bounds) |
| `selectedSpotId: string \| null` | 마커/리스트 행/페이저 탭 | 카메라 **panTo**(해당 스팟) |

파생(자체 state 금지): 마커 스타일(선택=확대+테두리) · 바텀시트/플로팅 카드 내용 · 리스트 활성 행(데스크톱) · 페이저 이전/다음 대상 · 마커 투명도(필터 외 dim)

카메라 원칙 (문법 6): 같은 맥락 이동 = panTo / 컨텍스트 전환 = jump.
파생 방향은 단방향: 칩 → 선택에 영향, 선택 → 칩 무영향.

#### 행위
| 행위 | 결과 |
|---|---|
| 마커 / 리스트 행 / 페이저 탭 | selectedSpotId 변경 → panTo |
| 작품칩 탭 | selectedMovieId 변경 → 선택 해제 + jump. 자동 선택 없음(사용자가 고른다) |
| "전체" 칩 | 필터 해제 → 선택 해제 + jump(전국 bounds) |
| "플랜에 담기" | MyPlan 연결 플로우 (상세는 MyPlan 명세에서) |
| 지도 드래그 | 카메라만 이동, **선택 유지** — 드래그는 시점 변경이지 선택 변경이 아님 |

#### 5줄 체크
- 로딩: 지도 영역 스켈레톤(기존 animate-pulse 유지) + 칩 행 스켈레톤
- 0건: 필터 결과 0건 → "이 작품의 촬영지가 아직 없어요" + 전체 보기 버튼
- 실패: SDK 로드 실패 문구 + **재시도 버튼 추가 필요** (현재 문구만 존재 — A001 확인)
- press: 칩·마커·카드 버튼·리스트 행에 active:scale
- 스캔: 거리("~역에서 N분", 주소 대신) · 리뷰 수 · 작품 배지 — 아이콘+숫자 쌍

#### 레이아웃 (문법 5)
- 모바일: 풀맵 + 바텀시트 (그립, 좌우 페이저)
- 데스크톱: 좌패널(검색+칩+리스트) + 풀맵 + 우하단 플로팅 카드

## ④ 디자인 문법 7개 (라이트바겐 분해, 확정)

1. **마커 = 미리보기** — 썸네일 + 이름 칩
2. **탐색 루프** — 선택 → 좌우 페이저로 연속 탐색
3. **사용자 관점 정보** — 주소 대신 거리, 기능 대신 혜택
4. **정보 밀도의 규율** — 같은 항목·같은 순서·필요한 것만
5. **풀맵 + 바텀시트**(모바일) / **좌패널 + 풀맵**(데스크톱)
6. **전환의 의도성** — 컨텍스트 전환 = jump, 같은 맥락 = panTo
7. **단일 선택 상태의 다중 파생** — selectedSpotId → 마커·목록·카드·카메라

- Dotrip 고유 시그니처: 점(dot) 모티프 — 점선 루트, 스틸컷 썸네일 마커, 점 타임라인, 내비 활성 점.

**완성 판정 = 5줄 체크** (모든 화면 공통):
로딩(콘텐츠 모양 스켈레톤) / 0건(안내 + 다음 행동) / 실패(안내 + 재시도) / press(터치 반응) / 정보(읽기가 아니라 스캔).
