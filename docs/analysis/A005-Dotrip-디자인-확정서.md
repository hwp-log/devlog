## 1. 방향 한 줄

**미니멀 + 토큰 일관성 + 실사진 밀도.** 화면은 필요한 것만 담고, 밀도는 텍스트가 아니라 스틸컷(실사진)이 채우며, 일관성은 감각이 아니라 토큰이 강제한다. (레퍼런스 검증: 에어비앤비 — 카드 정보 4개, 광대한 여백, 화면 크기와 무관한 컴포넌트 동일성)

## 4. 타임라인 무채색 원칙 (PlanFinder·MyPlan)

- 시작·끝 점 = 흰색/진한색, 중간 점·점선 = muted
- 카드 내 블루는 "코스 보기 →" 하나만 — 블루 남용 시 primary의 지시 기능이 죽는다
- 점선 루트는 동선이 존재하는 화면 한정 (SpotFinder 제외 — 탐색 화면이지 동선 화면 아님)

## 5. 타이포

| 역할 | 폰트 | 웨이트 |
|---|---|---|
| 헤드라인 · 카드 제목 · 로고 · 본문 · UI 전부 | **Pretendard Variable** | 본문 400 / 제목·CTA 600 |
| 숫자 · 날짜 · EP · 좌표 | DM Mono | 400 |

- **세리프(Noto Serif KR) 제거** — 에어비앤비 실측 결과 위계는 서체 교체가 아니라 크기·색으로 만든다는 결론. Pretendard 단일 체계로 전환.
- **700 사용 금지.** 위계는 굵기가 아니라 크기 · 색(fg↔muted) · 자간으로.
- 헤드라인 크기 22→16px. 화면 상단은 제목이 아니라 도구다.

## 6. 화면 카피 (기능 설명형 전면 전환)

| 화면 | 카피 |
|---|---|
| Story | 여행자들의 이야기 |
| SpotFinder | 영화·드라마 촬영지 검색 |
| PlanFinder | 여행자들의 계획 |

- 서정 카피("그 장면, 다녀왔습니다" 등)는 화면에서 제거, 랜딩·서비스 소개로 이전
- **규율 2 개정: 화면 카피 = 기능어만.** 근거: 에어비앤비 실측 + 여행은 정보 과포화 도메인이라 화면 안에서 감성 문장은 소음이 된다

## 7. 규율 5 (규율 2만 개정, 나머지 유지)

1. **정보 상한**: 카드의 스캔 정보는 4±1개 (스틸컷 + 장소명 + 작품 배지 + 거리/별점). 그 이상은 상세로.
2. **카피 절제 (개정)**: 화면 카피는 기능어만. 감성 카피는 랜딩·소개 전용.
3. **모션 최소**: press(scale) · 선택 글로우 · 상태 전환만. 장식 모션 금지. prefers-reduced-motion 존중.
4. **밀도는 사진이 채운다**: 허전함은 텍스트가 아니라 스틸컷 크기/수로 해결.
5. **일관성 = 컴포넌트 속성**: SpotCard·WorkChip·Marker·EmptyState는 단일 컴포넌트, 화면 폭은 그릇만 바꾼다.
