> 조사 성격: **읽기 전용 현황 보고**. 개선 제안·수정 없음.
> 조사 대상: `app/`, `components/`, `lib/` (node_modules·.next·`__tests__` 제외).

> 조사일 기준 라우트 17개(page.tsx) / 클라이언트 컴포넌트 다수.

## 1. 페이지·주요 컴포넌트별 기능 / 데이터

라우트 경로 기준. 데이터는 서버 조회 테이블/소스 위주.

### 공개 / 인증

**`/` — app/page.tsx**
랜딩. Supabase `auth.getUser()`만 조회 → 로그인 상태면 `/story`로 redirect. 브랜드 카피(Dotrip, 한/일) + 회원가입/로그인 CTA. DB 조회 없음.

**`/login` — app/(auth)/login/page.tsx**
로그인. 서버 조회 없음. `loginAction`(server action)을 `LoginForm`에 전달. 좌 브랜드 소개 + 우 폼.

**`/signup` — app/(auth)/signup/page.tsx**
회원가입. 서버 조회 없음. `signupAction`을 `SignupForm`에 전달. 구성은 login과 대칭.

### Story (기록)

**`/story` — app/story/page.tsx**
스토리 목록 + 태그 검색. `fetchStoriesWithMeta({tag})`, `fetchPopularTags()`, `prisma.like.findMany`(내 좋아요 집합). content에서 썸네일/미리보기 추출 후 `StoryCardList`에 전달. `searchParams.q`로 태그 필터.

**`/story/[id]` — app/story/[id]/page.tsx**
스토리 상세. `prisma.story.findUnique`(tags, spots+movie.title, plan+costs+flight, _count.likes, user) + 내 좋아요를 `Promise.all`. 없으면 `notFound()`. `summarizePlanCost`로 공개 예산 요약, spots를 지도(`SpotMap`)에 렌더. 소유자면 수정/삭제 노출.

**`/story/new` — app/story/new/page.tsx**
스토리 작성. 비로그인 시 `/login`. `prisma.myPlan.findMany`(본인·story 미연결)로 연결 가능 플랜 조회 → `StoryWriteForm`에 `createStoryAction`과 전달.

**`/story/[id]/edit` — app/story/[id]/edit/page.tsx**
스토리 수정. `prisma.story.findUnique`(tags, spots+movie.title), 없으면 `notFound()`, 비소유자 redirect. 연결 가능/현재 연결 플랜 조회 후 `updateStoryAction.bind`로 폼에 전달.

### Admin (작품 관리)

**`/admin` — app/(protected)/admin/page.tsx**
작품(movie) 관리. `movie.findMany` 2건 병렬(PENDING/APPROVED, 각 `_count.spots`, createdAt desc). PENDING 각 건에 `findMergeCandidates(title,3)`로 유사 승인작 후보. 승인 대기/승인됨 섹션 → Pending/ApprovedMovieRow.
- `admin/layout.tsx`: 접근 가드. 미로그인·비ADMIN 시 `/` redirect. UI 없음.

### My (개인)

**`/my-plan` — app/(protected)/my-plan/page.tsx**
내 여행계획 목록. `myPlan.findMany`(ownerId, costs+flight+_count.spots) → `calcPlanTotal`/`summarizePlanCost` 가공 → `MyPlanListClient`.

**`/my-plan/new` — .../new/page.tsx**
계획 작성. 자체 조회 없음. `MyPlanNewForm`(mode 기본) 렌더.

**`/my-plan/[id]` — .../[id]/page.tsx**
계획 상세. `myPlan.findFirst`(id+ownerId, spots+costs+flight). 미인증 `/login`, 없으면 `notFound()`. `dayCount` 계산 후 `PlanDetail`에 전달.

**`/my-plan/[id]/edit` — .../[id]/edit/page.tsx**
계획 편집. 위와 동일 조회 → `buildInitialState()`로 `EditorState` 변환 → `MyPlanNewForm`(mode="edit").

**`/my-dots` — app/(protected)/my-dots/page.tsx**
내 스토리(MyStory) 목록 + 태그 검색. `fetchStoriesWithMeta({userId,tag})`, `fetchMyStoryTags`, `like.findMany`. `MyStoryCardGrid` 렌더, `TagSearchBar`·`ViewTransition` 사용.

**`/mypage` — app/(protected)/mypage/page.tsx**
마이페이지. `Promise.all` 7개 병렬(user, story.count, myPlan.count, like.count, plansForAvg, recentStories(3), recentPlans(3)). `calcPlanTotal`로 평균비용. Avatar/Nickname/Password/DangerZone/ActivityDashboard/RecentActivity 카드로 분배.

### Finder (탐색)

**`/plan-finder` — app/(protected)/plan-finder/page.tsx**
공개 플랜 목록. `fetchPublicPlans(user?.id)` → `PlanFinderHeader` + `PlanListClient`. 0건 시 빈 상태.

**`/plan-finder/[id]` — .../[id]/page.tsx**
공개 플랜 상세. `myPlan.findFirst`(id, isPublic, spots+costs+flight+owner+_count.planLikes+조건부 planLikes). 서버에서 금액/항공 시간 제거(비공개화) 후 `PlanFinderDetail`에 다수 props. 없으면 `notFound()`.

**`/spot-finder` — app/(protected)/spot-finder/page.tsx**
촬영지 지도. `fetchSpotFinderSpots()` → `SpotFinderHeader` + `SpotFinderMapWrapper`(spots).

### TIL

**`/til` — app/(protected)/til/page.tsx**
TIL 목록. `getTilEntries()`(id/title/content/created_at/type). type별 배지. 에러/빈 상태/카드 그리드 분기.

**`/til/[id]` — .../[id]/page.tsx**
TIL 상세. `getTilEntry(id)`, 에러 시 `notFound()` → `TilDetail`.

**`/til/new` — .../new/page.tsx**
TIL 작성. 조회 없음. `createTilEntryAction`을 `TilForm`에 전달하는 정적 셸.

## 3. 터치 / press 반응 클래스 (`active:` 계열) 사용 현황

> `active:` / `:active` / `group-active` 를 실제 스타일로 쓰는 파일은 **3개뿐**.
> (`BottomTabBar`·`NavLinks`의 `active`는 CSS가 아니라 JS 판정 변수명 → 제외. 나머지 인터랙션은 전부 `hover:` 계열.)

| 파일 | 위치 | 클래스 문자열 |
|---|---|---|
| `app/(protected)/my-plan/page.tsx` | L92, L109 | `active:translate-y-0 active:scale-[0.96] active:duration-100` |
| `app/(protected)/my-dots/page.tsx` | L113 | `active:translate-y-0 active:scale-[0.96] active:duration-100` |
| `components/SpotList.tsx` | L64 | `cursor-grab active:cursor-grabbing hover:text-slate-600` |

그 외 전 조사 파일: **없음**. (즉 목록 카드·버튼 대부분은 press 피드백 없이 hover만 존재 — 모바일 터치 반응 부재 구간.)

## 4. 텍스트로만 표시 중인 정보 (아이콘화 후보 — 넓게 수집)

> 선별 전 원자료. "아이콘 동반"으로 표기된 항목은 이미 아이콘이 붙어 있으나 인접 텍스트라 참고용 수집.

- 드롭다운 항목: `MyPage` `MyPlan` `MyStory` `Admin` `SignOut` (UserDropdown, 전부 텍스트만) / 이메일 truncate / 이니셜
- `로그아웃` (LogoutButton) · `Write`(layout, PenSquare 동반) · `로그인`(비로그인)
- Logo `D…trip`

### 헤더 라벨 + 랜덤 헤드라인 (모두 텍스트, 아이콘 없음)
- `Story` / `MyStory` / `MyPlan` / `MyPage` / `PlanFinder` / `SpotFinder` / `Admin` 오버라인 라벨
- StoryHeader 3종 · PlanFinderHeader 4종 · SpotFinderHeader 3종 랜덤 문구

### 랜딩 / 인증
- 배지 `TRAVEL` `PLAN` `RECORD` · 버튼 `회원가입` `로그인`
- `Sign In` `Sign Up` 헤딩 / 서브카피 / 구분선 `또는` / "아직 계정이…" "이미 계정이…"

### 카드 · 목록 공통 (아이콘 유무 혼재)
- 날짜: StoryCard `YYYY.M.D`, story상세 `toLocaleDateString('ko-KR')`, PlanCard(Calendar 동반), til `<time>`
- 카운트: 좋아요 `{likeCount}`(Heart 동반), 태그초과 `+{n}`, 통계줄 "N 게시물 · M 좋아요"(my-dots), "N개 계획/코스 · 평균 약 X만원"
- 태그 `#{name}`(배지, 아이콘 없음) · "이미지 없음" · 작성자 닉네임
- 가격 "약 N만~M만원" / "금액 없음" / "예산 미입력"
- region·movie pill (MapPin/아이콘 동반)

### Admin
- 섹션 헤더 `승인 대기 (N)` `승인됨 (N)` · 페이지 제목 `작품 관리`
- 메타 `Spot N개 · YYYY-MM-DD` · 버튼 `승인` `거절` `저장` `취소` `수정` `대기로 되돌리기`
- `유사한 승인 작품:` · 병합버튼 `{title} (Spot N개)(으)로 병합`

### My-Plan / 비용
- CostSection: `카테고리별 비용` `항공`(SVG 동반) `교통/숙박/식비/입장료/기타` 라벨 · 금액 `₩{n}` / `총 비용`

- MyPlanCard: 제목 · region/기간 pill · `{ratio}%` · `+{n}` · `예산 미입력` · 총액
- PlanTimeline: 순번 `{i+1}` · spot 이름 · 금액/`무료`
- MyPlanListClient: 필터 라벨값 `전체/~50만/50~100만/100만~`, 정렬 `최신순/시작일순/가격 낮은순/가격 높은순`, 드롭다운 라벨 `가격대`·`정렬`
- 버튼 `새 계획`
